## Q1：prior 是什么意思？overextension 形态是之前确认的吗，其他形态都失败了吗

**"prior"** = "在信号触发之前"的意思，是时间前缀：

```
prior 1h 跌超 0.8%
= 在这根信号 K 线发出之前的 1 小时内，ETH 已经下跌了 0.8% 以上
```

不是模型的预测，是进场时的客观市场背景。

**这个形态是在分析中事后发现的，不是之前预先设计的。** 它在 v1 和 v1.0.1 两份报告中都稳定出现，跨越了两个分析周期，所以可以认为是真实的。

其他形态的现状：

| 形态假设 | 扩展数据结论 |
|---------|-----------|
| SHORT 信号有效 | ❌ 失效，22.2% 胜率（v1.0.1） |
| FLAT 震荡信号有效 | ❌ 失效，11.8%（v1.0.1）/ 32.1%（v1） |
| 高置信度（0.7–0.8）比低置信度更好 | ❌ 失效，反而更差（32.7% < 43.5%） |
| 13:xx / 07:xx 时段可用 | ❌ 两版本均 0% 胜率，系统性失效 |
| **Overextension LONG** | ✅ 两个周期稳定，v1.0.1 75% |
| **Isolated（非 cascade）** | ✅ v1 56.2%，独立有效的过滤维度 |

## Q2：还有哪些形态胜率相对较高，可以继续做的

除了 overextension，还有 **2 个值得跟进** 的方向：

**① 孤立信号（Isolated，非 cascade）**

v1 孤立信号胜率 56.2%（18/32），这是一个独立于 overextension 的维度。判断标准：过去 30 分钟内**没有同方向前序信号**。它现在只是分析维度，还没有作为过滤规则加进模型，但数据支持加进去。

**② 09:xx / 21:xx CST 时段**

| 时段 | v1 胜率 | v1.0.1 胜率 | 信号数 |
|------|--------|-----------|------|
| 09:xx | 57.1% | 50.0% | 少（7/2） |
| 21:xx | 62.5% | 40.0% | 少（8/5） |

方向正确，但样本太少（<10）还不能确认，需要更长运行期验证。

**③ AGST（逆势）+ overextension 的交集**

v1.0.1 AGST 胜率 50%，overextension 胜率 75%，两者交集估计 >75%——事实上 overextension 信号几乎全是 AGST 方向，这两个条件本质上是同一个形态的两种描述角度，不是独立的。

## Q3：失效的形态，要不要删掉

**看层次，不是删"形态"，是加"规则"。**

这些"形态"大多数不是模型的输出特征，是信号触发后的环境分类（时段、趋势状态、cascade 判断）。有两类处理方式不同：

**应该加硬过滤的（在触发层直接拦截）：**
- `hour in [7, 13]` → 强制不出单
- `trend_1h == FLAT` → 跳过
- `direction == SHORT`（短期内）→ 关闭

这些不是"删除"，是在模型输出之后加一层门控，模型本身不动。

**不应该删除的：**
- SHORT 模型头：未来如果要重训 SHORT，样本仍需要这头产生候选信号
- FLAT 信号的训练样本：它们告诉模型"这类场景不好"，完全删掉训练样本会让模型对 FLAT 场景失去判断力

## Q4：v1 有哪里真的优于 v1.0.1

有两处，但一真一假：

**真实优势：SHORT 胜率更好**

| 模型 | SHORT 胜率（24h） | 信号数 |
|------|----------------|------|
| v1 | **40.0%** | 30 |
| v1.0.1 | 22.2% | 18 |

v1.0.1 的 `tbr_trend` 特征对 SHORT 是有害的——在市场局部反弹时 tbr 上升，模型误判为 SHORT 机会（认为买入动能消退），结果进了反弹的 SHORT 全部失败。v1 没有这个干扰，SHORT 判断反而更干净。这是**真实的**。

**虚假优势：Isolated 信号胜率（v1 56.2% > v1.0.1 40.9%）**

看起来 v1 孤立信号更好，但原因是 v1.0.1 的孤立信号里包含了更多 Cascade 边缘信号（v1.0.1 在某些场景触发更频繁），混入了质量差的信号。不是 v1 本身更准，而是 v1.0.1 多出的信号把这个均值拉低了。

## Q5：三头模型中 ymax、ymin 和方向头如何匹配

**三头的定义：**

| 头 | 训练目标 | 输出 |
|----|---------|------|
| 方向头（LONG/SHORT） | "在 N 根 K 线内，是先触 +R% 还是先触 −R%？" | 0~1 概率 |
| ymax 头 | "N 根 K 线内最高涨幅是多少？" | 回归值（%） |
| ymin 头 | "N 根 K 线内最大跌幅是多少？" | 回归值（%） |

**重合是真实存在的问题：**

方向头预测的本质就是 `P(ymax 先被触及)`，而这在理论上完全由 ymax 和 ymin 的大小关系决定。三头预测的是同一件事情的三个角度，它们之间存在**逻辑约束**：

$$\text{如果 } y_{max} > y_{min} \Rightarrow \text{应该 LONG，方向头概率应} > 0.5$$

但三个独立的 XGBoost 模型分别训练，**没有任何机制强制这个约束**，所以可能出现：
- 方向头说 LONG（概率 0.78），但 ymax=0.3%，ymin=0.6%（下行空间更大）→ 矛盾

信号里的 R-ratio（TP/SL 比）正是来自 ymax/ymin，而概率来自方向头，**两者现在是独立估计**，没有互相校验。

**分开训练也可以，但要在推理时做一致性检查：**

```python
# 当前（可能有矛盾的输出）：
long_prob = long_model.predict(X)   # 0.78
r_ratio   = ymax_model.predict(X) / ymin_model.predict(X)  # 0.5x（矛盾！）

# 建议加一层一致性门控：
if long_prob > threshold and r_ratio < 1.0:
    # 方向头说 LONG 但 ymax < ymin，信号降级或过滤
    skip_or_downgrade()
```

**是否需要合并？** 不一定。分开训练的好处是每个头可以独立调优（比如 ymax 用回归损失，方向头用分类损失）。只要推理时做一致性约束，就够了。如果要真正消除重合，就需要换成神经网络架构做多任务学习，共享特征层——那是另一个体量的工程。
