## 三、问题诊断

### 可能性1：模型训练数据问题 ❌

**检查**：
- v2模型训练日期：2026-04-22
- v3模型训练日期：2026-04-23
- 模型文件存在且完整（3.5MB）

**结论**：模型已经重新训练，不是这个问题

### 可能性2：特征不匹配 ❌

**检查**：
- v2模型：134特征
- v2推理：应该也是134特征（新增了4个）
- v3模型：137特征
- v3推理：应该也是137特征（新增了3个）

**结论**：特征数量匹配，不是这个问题

### 可能性3：新特征导致模型过于保守 ✅ 最可能

**分析**：

#### v2新增的方向性动量特征

```python
ret_net_30m_5m    # 30分钟净收益率
ret_net_1h_5m     # 1小时净收益率
ret_net_4h_5m     # 4小时净收益率
up_bars_6_5m      # 连续上涨K线数
```

**问题**：
- 这些特征是"长期趋势"指标（30m/1h/4h）
- 但我们的预测目标是"30分钟内涨0.8%"（短期）
- **长期趋势 vs 短期预测 = 不匹配**

**举例**：
```
当前状态：
- ret_net_1h_5m = -0.5%（1小时下跌）
- ret_net_4h_5m = -1.0%（4小时下跌）
- up_bars_6_5m = 0（没有连续上涨）

模型判断：
- 长期趋势向下
- 即使短期有反弹信号，也不敢触发
- LONG prob = 0.008（极低）
```

**实际情况**：
- 2026-04-27 13:15，价格从2393跌到2344（-2.05%）
- v1识别出"跌多了，该反弹"，触发LONG（prob=0.7687）
- v2看到"1小时/4小时都在跌"，不敢触发（prob=0.008）

#### v3新增的订单流特征

```python
buy_ratio_30m_5m  # 30分钟买入占比
buy_ratio_1h_5m   # 1小时买入占比
buy_ratio_4h_5m   # 4小时买入占比
```

**问题**：
- 同样是"长期"指标（30m/1h/4h）
- 如果1小时内买入占比低（卖方强）
- 模型不敢触发LONG信号

**举例**：
```
当前状态：
- buy_ratio_1h_5m = 0.35（1小时内买入占比35%，卖方强）
- buy_ratio_4h_5m = 0.40（4小时内买入占比40%，卖方强）

模型判断：
- 长期卖方力量强
- 即使短期有反弹信号，也不敢触发
- LONG prob = 0.008（极低）
```

## 四、为什么v1能触发信号？

### v1的特征设计

v1的130个特征主要是：
- **短期指标**：1m/5m/15m的价格、动量、波动率
- **中期指标**：1h/4h的趋势、RSI、MACD
- **没有"长期净收益率"和"长期买入占比"**

**关键区别**：
- v1的1h/4h特征是"状态"（RSI、MACD、ATR）
- v2/v3的1h/4h特征是"方向"（净收益率、买入占比）

**举例**：
```
v1看到的：
- rsi_1h = 30（超卖）
- macd_hist_1h = -0.5（负值但收敛）
- atr14_1h = 高波动
→ 判断：超卖 + 波动大 = 可能反弹

v2看到的：
- ret_net_1h_5m = -0.5%（1小时下跌）
- buy_ratio_1h_5m = 0.35（卖方强）
→ 判断：下跌 + 卖方强 = 不敢做多
```

## 五、根本原因分析

### 特征设计的哲学问题

**v1的设计哲学**：
- 识别"市场状态"（超买/超卖/高波动/低波动）
- 基于状态预测"短期反转"
- **适合30分钟短期交易**

**v2/v3的设计哲学**：
- 识别"长期趋势"（1小时/4小时涨跌）
- 基于趋势预测"趋势延续"
- **适合1-4小时中期交易**

**冲突**：
- 预测目标：30分钟内涨0.8%（短期）
- 新增特征：1小时/4小时趋势（长期）
- **短期目标 + 长期特征 = 不匹配**

### 模型学到了什么？

**v2/v3模型的学习结果**：
```
IF 1小时下跌 AND 4小时下跌 AND 买入占比低
THEN 不要做多（即使短期有反弹信号）
```

**问题**：
- 这个逻辑在训练数据上可能是对的
- 因为"逆势交易"（1小时下跌时做多）胜率低
- 但这导致模型**过于保守**，错过很多机会

**实际案例**：
- 2026-04-27 13:15，价格从2393跌到2344
- v1：识别出"跌多了，该反弹"，触发LONG
- v2/v3：看到"1小时/4小时都在跌"，不敢触发
- **结果**：v1抓住了反弹机会（虽然止损了），v2/v3完全错过

## 六、解决方案

### 方案1：移除长期方向性特征（推荐）

**操作**：
- 从v2中移除：ret_net_30m/1h/4h, up_bars_6
- 从v3中移除：buy_ratio_30m/1h/4h
- 保留短期特征（1m/5m/15m）

**原因**：
- 30分钟预测目标 + 长期特征 = 不匹配
- 长期特征让模型过于保守

### 方案2：改变预测目标（不推荐）

**操作**：
- 将预测目标从"30分钟内涨0.8%"改为"1-2小时内涨1.5%"
- 匹配长期特征

**原因**：
- 这样就变成了"趋势跟踪模型"
- 不再是"短期反转模型"
- 需要重新设计止盈止损逻辑

### 方案3：分离短期和长期特征（最佳）

**操作**：
- v1：短期反转模型（30分钟目标）
  - 特征：1m/5m/15m
  - 逻辑：识别超买/超卖，预测反转
  
- v2：中期趋势模型（1-2小时目标）
  - 特征：1m/5m/15m + 1h/4h方向性特征
  - 逻辑：识别趋势，预测延续

**优势**：
- 两个模型各司其职
- v1抓短期反转
- v2抓中期趋势
- 可以同时运行，互补

## 八、总结

### 核心问题

**v2/v3没有信号的根本原因**：
- ❌ 不是模型没训练
- ❌ 不是特征不匹配
- ✅ **是新增的长期方向性特征让模型过于保守**

### 特征设计的教训

**错误的做法**：
- 预测目标：30分钟短期
- 添加特征：1小时/4小时长期
- 结果：模型不敢触发信号

**正确的做法**：
- 短期目标 → 短期特征（1m/5m/15m）
- 长期目标 → 长期特征（1h/4h/1d）
- **目标和特征的时间尺度要匹配**
