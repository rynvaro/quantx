# QuantX v1 特征体系深度分析

## 一、特征体系概览

### 1.1 基本架构

**预测目标**：未来 30 分钟（HORIZON=30 个 1 分钟 K 线）内的价格变动
- `y_max`: 最大涨幅（LONG）或最大跌幅（SHORT）
- `y_min`: 最大回撤（LONG）或最大反弹（SHORT）
- `y_class`: 是否达到 1% 入场阈值

**特征总数**：130 个技术指标特征 + 1 个时间特征（hour_of_day）

**时间尺度分布**：
- 1m（微观）：34 个特征 - 捕捉瞬时波动和加速度
- 5m（短期）：34 个特征 - 捕捉短期趋势和触发信号
- 15m（中短期）：33 个特征 - 捕捉中短期动量
- 1h（中期）：10 个特征 - 捕捉中期趋势和超买超卖
- 4h（宏观）：15 个特征 - 捕捉大周期趋势和市场状态
- 其他：3 个（funding_rate, hour_of_day, day_of_week）

## 三、模型的预测逻辑推演

### 3.1 模型"看到"的市场

基于特征重要性分布，v1 模型的决策逻辑可以推演为：

#### **第一层：波动率筛选（61.9% 重要性）**

模型首先通过 **atr14_1m**（占 50.9%）判断：
- **高波动 = 机会**：ATR 突然放大 → 价格开始剧烈波动 → 可能出现 1% 的移动
- **低波动 = 等待**：ATR 压缩 → 价格横盘 → 不太可能达到 1% 目标

**推论**：模型是一个"波动率猎手"，它不预测方向，而是预测"接下来会不会有大波动"。

#### **第二层：位置判断（10.6% 重要性）**

通过 **bb_position_1h/4h** 和 **rsi14_1h/5m** 判断：
- **价格在布林带下轨 + RSI < 30** → LONG 信号（超卖反弹）
- **价格在布林带上轨 + RSI > 70** → SHORT 信号（超买回落）

**推论**：模型偏好"均值回归"策略，在极值区域寻找反转机会。

#### **第三层：趋势确认（11.0% 重要性）**

通过 **ema_cross_1h/15m** 和 **macd_hist** 判断：
- **EMA9 上穿 EMA21 + MACD > 0** → 确认上升趋势
- **EMA9 下穿 EMA21 + MACD < 0** → 确认下降趋势

**推论**：模型会在趋势方向上寻找入场点，但趋势判断的权重远低于波动率。

#### **第四层：动量加速（7.8% 重要性）**

通过 **roc1/3/5_15m** 和 **roc_accel** 判断：
- **连续正加速度** → 价格加速上涨，可能继续
- **加速度转负** → 动能衰竭，可能反转

**推论**：模型会捕捉"加速启动"的瞬间，但这不是主要决策因素。

### 3.2 模型的盲点

#### **致命缺陷 1：缺少长期趋势感知**

- **4h 特征仅占 6.1%**：ema200_4h（259）、trend_score_4h（未进 Top 50）
- **没有日线/周线特征**：无法判断是牛市还是熊市
- **结果**：SHORT 模型在 2021 年牛市初期爆仓（4 天亏光），因为它不知道"现在是牛市，不该做空"

#### **致命缺陷 2：过度依赖 1 分钟波动率**

- **atr14_1m 占 50.9%**：模型几乎完全依赖瞬时波动率
- **问题**：1 分钟 ATR 可以被单根大阴/阳线扭曲，容易产生假信号
- **结果**：在剧烈波动中频繁触发信号，但很多是"噪音"而非"趋势"

#### **致命缺陷 3：预测窗口与特征尺度不匹配**

- **预测目标**：未来 30 分钟（150 分钟）的价格变动
- **主要特征**：1m（瞬时）、5m（5 分钟）、15m（15 分钟）
- **问题**：用"秒级/分钟级"的特征预测"半小时级"的结果，时间尺度错配

**类比**：就像用"过去 1 秒的加速度"预测"未来 30 分钟会开到哪里"。

## 四、模型适合预测多久的行情？

### 4.1 理论分析

基于特征的时间尺度分布，模型的"有效预测窗口"应该是：

| 特征尺度 | 占比 | 适合预测的时间窗口 |
|---------|------|-------------------|
| 1m（瞬时） | 26.2% | 1-5 分钟 |
| 5m（短期） | 26.2% | 5-15 分钟 |
| 15m（中短期） | 25.4% | 15-30 分钟 |
| 1h（中期） | 7.7% | 30-60 分钟 |
| 4h（宏观） | 11.5% | 2-4 小时 |

**加权平均预测窗口**：
```
(1m × 26.2% + 5m × 26.2% + 15m × 25.4% + 1h × 7.7% + 4h × 11.5%) / 100%
≈ 3.3 分钟 + 13.1 分钟 + 3.8 分钟 + 4.6 分钟 + 27.6 分钟
≈ 52.4 分钟
```

但考虑到 **atr14_1m 占 50.9%**，实际的"决策时间尺度"更接近 **5-15 分钟**。

### 4.2 实证验证

从 2025 年回测结果看：

**LONG 模型**：
- 平均持仓时间：未统计，但从 TP=+0.92%, SL=-0.15% 推算约 **10-30 分钟**
- 胜率 79.1%：说明短期预测能力强
- 最大回撤 -6.3%：说明风险控制良好

**SHORT 模型**：
- 平均持仓时间：类似 LONG
- 胜率 78.5%：短期预测能力也强
- 但在 2021 年牛市爆仓：说明**缺少长期趋势过滤**

### 4.3 结论

**v1 模型最适合预测的时间窗口是：10-20 分钟**

**理由**：
1. **特征尺度匹配**：15m 特征占 25.4%，是除 1m 外最重要的时间尺度
2. **TP/SL 设置**：TP=+0.92% 在正常波动下需要 10-30 分钟达到
3. **回测表现**：在 2025 年（震荡市）表现优秀，说明短期预测有效

**但当前 HORIZON=30 分钟的问题**：
- **预测窗口过长**：30 分钟内市场状态可能变化多次
- **标签噪音大**：30 分钟内的 y_max 可能包含多次反转，不是"一次性移动"
- **建议**：将 HORIZON 改为 **15-20 分钟**（15-20 个 1m bar），更匹配特征尺度

## 五、模型能否推演出未来行情？

### 5.1 模型的本质

v1 模型不是"预测未来"，而是**识别当前市场状态**：

| 市场状态 | 特征表现 | 模型输出 | 实际含义 |
|---------|---------|---------|---------|
| **波动率突然放大** | atr14_1m ↑↑ | 高概率信号 | "现在开始波动了，可能有机会" |
| **超卖 + 反弹启动** | bb_position_1h < 0.2, rsi14_1h < 30, roc1_15m > 0 | LONG 信号 | "价格在底部且开始反弹" |
| **超买 + 动能衰竭** | bb_position_1h > 0.8, rsi14_1h > 70, roc_accel < 0 | SHORT 信号 | "价格在顶部且加速度转负" |
| **横盘压缩** | atr14_1m ↓, compress_bars ↑ | 低概率/不触发 | "现在没有波动，等待" |

**关键洞察**：模型是一个"模式识别器"，它学到了：
- "什么样的市场状态下，接下来 10-20 分钟容易出现 1% 的移动"
- 而不是"价格会涨到多少"

### 5.2 模型的预测能力边界

#### **能预测的**：
1. **短期波动率**：未来 10-20 分钟是否会有剧烈波动（准确率高）
2. **均值回归**：超买/超卖区域的反转（在震荡市有效）
3. **加速启动**：价格开始加速时的惯性延续（短期有效）

#### **不能预测的**：
1. **长期趋势**：未来 1 小时/4 小时/1 天的方向（特征不足）
2. **趋势反转点**：牛市顶部/熊市底部（缺少宏观特征）
3. **黑天鹅事件**：突发新闻、大额爆仓、交易所故障（无法从历史数据学习）

### 5.3 为什么 2025 年表现好，2021 年爆仓？

**2025 年（震荡市）**：
- 市场在一个区间内反复波动
- 超买/超卖 → 均值回归 → 模型的强项
- 短期波动率预测有效 → 胜率 78-79%

**2021 年初（牛市启动）**：
- 市场处于单边上涨趋势
- SHORT 信号触发时，价格短暂回调后继续上涨
- 模型不知道"现在是牛市" → 连续止损 → 4 天爆仓

**类比**：
- v1 模型像一个"短线交易员"，擅长在震荡市中高抛低吸
- 但它没有"宏观视野"，不知道现在是牛市还是熊市
- 就像一个只看 K 线图的交易员，不看新闻、不看基本面

## 六、改进方向

### 6.1 短期改进（保持 v1 架构）

1. **调整 HORIZON**：
   - 从 30 分钟改为 **15-20 分钟**
   - 更匹配特征的时间尺度
   - 减少标签噪音

2. **添加趋势过滤器**（已在 v1.1.0 实现但未合并）：
   - 在 run_signal.py 添加 EMA20/60 斜率判断
   - LONG 只在上升趋势触发，SHORT 只在下降趋势触发
   - 不改变模型，只在推理时过滤

3. **降低 atr14_1m 的权重**：
   - 在特征工程中添加 atr14_1m 的平滑版本（EMA5）
   - 或者用 atr14_5m 替代 atr14_1m
   - 减少对瞬时噪音的敏感度

### 6.2 中期改进（v2/v3 方向）

1. **添加方向性特征**（v2 已实现）：
   - ret_net_30m/1h/4h_5m：长期净收益率
   - up_bars_6_5m：连续上涨 K 线数
   - 让模型学会"判断趋势方向"

2. **添加宏观趋势特征**：
   - 日线 EMA50/200 的位置和斜率
   - 周线趋势强度
   - 让模型知道"现在是牛市还是熊市"

3. **多目标优化**：
   - 不只预测 y_class（是否达到 1%）
   - 同时预测"持仓时间"和"最大回撤"
   - 优化风险调整后收益，而不是单纯的胜率

### 6.3 长期改进（架构升级）

1. **分层模型**：
   - 第一层：宏观趋势模型（日线/周线特征，预测未来 1-7 天方向）
   - 第二层：中观波段模型（4h/1h 特征，预测未来 4-24 小时方向）
   - 第三层：微观入场模型（当前 v1，预测未来 10-20 分钟入场点）
   - 只有三层都同意时才触发信号

2. **市场状态分类**：
   - 训练一个"市场状态分类器"（牛市/熊市/震荡市）
   - 为每种状态训练独立的模型
   - 推理时先判断状态，再选择对应模型

3. **强化学习**：
   - 用 RL 优化"何时入场、何时止盈止损"
   - 目标函数：最大化夏普比率，而不是胜率
   - 让模型学会"在不确定时减小仓位"

## 七、总结

### 7.1 v1 模型的本质

**v1 是一个"短期波动率猎手 + 均值回归交易员"**：
- 它擅长识别"接下来 10-20 分钟会有剧烈波动"的时刻
- 它偏好在超买/超卖区域寻找反转机会
- 它在震荡市表现优秀，但在单边趋势市容易失效

### 7.2 预测能力评估

| 预测目标 | 预测窗口 | 准确率 | 适用市场 |
|---------|---------|--------|---------|
| **短期波动率** | 10-20 分钟 | ★★★★★ | 所有市场 |
| **均值回归** | 10-30 分钟 | ★★★★☆ | 震荡市 |
| **趋势延续** | 10-20 分钟 | ★★★☆☆ | 趋势市 |
| **趋势反转** | 30-60 分钟 | ★★☆☆☆ | 震荡市 |
| **长期方向** | 1-4 小时 | ★☆☆☆☆ | 不适用 |

### 7.3 核心建议

1. **接受模型的局限性**：v1 不是"圣杯"，它只在特定市场状态下有效
2. **添加趋势过滤**：在推理时过滤逆势信号，避免在牛市做空/熊市做多
3. **缩短预测窗口**：HORIZON 从 30 分钟改为 15-20 分钟
4. **收集实盘数据**：通过形态标记功能，识别哪些市场状态下模型最有效
5. **迭代优化**：基于实盘反馈，逐步添加宏观趋势特征（v2/v3 方向）

**最重要的**：v1 模型已经证明了"机器学习可以从市场数据中学到有用的模式"，现在的任务是"让它知道什么时候该用、什么时候不该用"。
