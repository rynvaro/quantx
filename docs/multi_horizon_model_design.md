# 多时间窗口预测模型设计方案

## 一、设计目标

训练多个独立模型，预测不同时间窗口内价格是否会触及目标阈值，找出预测准确率最高的模型。

**核心原则**：
- 当前阶段只关注**预测准确率**，不考虑交易策略和盈利
- 每分钟滚动预测一次（不是下单后等待）
- 每个模型独立训练和评估

---

## 二、模型架构

### 2.1 时间窗口与阈值

基于数据探索结果，设计以下组合：

| 时间窗口 | 推荐阈值 | 自然成功率 | 目标胜率 | 平均达到时间 |
|---------|---------|-----------|---------|------------|
| **M15** (15分钟) | 0.5% | 14.2% | >70% | ~9 分钟 |
| **M30** (30分钟) | 0.8% | 11.8% | >70% | ~18 分钟 |
| **H1** (60分钟) | 1.0% | 14.9% | >75% | ~30 分钟 |
| **H2** (120分钟) | 1.5% | 14.0% | >70% | ~72 分钟 |

**实验策略**：每个时间窗口训练 3 个不同阈值的模型，对比效果

| 时间窗口 | 实验阈值 |
|---------|---------|
| M15 | 0.3%, 0.5%, 0.8% |
| M30 | 0.5%, 0.8%, 1.0% |
| H1 | 0.8%, 1.0%, 1.5% |
| H2 | 1.0%, 1.5%, 2.0% |

### 2.2 标签定义

**多标签分类**：每个样本有 2 个独立的二分类标签

```python
# LONG 标签
y_long = 1 if (未来 N 分钟内最高价 >= 当前价 × (1 + threshold)) else 0

# SHORT 标签  
y_short = 1 if (未来 N 分钟内最低价 <= 当前价 × (1 - threshold)) else 0
```

**可能的组合**：
- `y_long=1, y_short=0` → 单边上涨
- `y_long=0, y_short=1` → 单边下跌
- `y_long=1, y_short=1` → 双向波动（<2% 样本，同时作为两个模型的正样本）
- `y_long=0, y_short=0` → 横盘震荡

**训练方式**：
- 为每个（时间窗口 × 阈值）组合训练 **2 个独立模型**（LONG + SHORT）
- 复用 v1 的 XGBoost 3-head 架构（classifier + TP/SL regressors）

### 2.3 评估指标

**只关注预测准确性**：
- **准确率** (Accuracy)
- **精确率** (Precision)：预测为正时，实际为正的比例
- **召回率** (Recall)：实际为正时，预测为正的比例
- **F1 分数**：精确率和召回率的调和平均
- **ROC-AUC**：模型区分能力

**不考虑**：盈利、夏普比率、最大回撤（这些是下一阶段的事）

## 三、特征工程设计

### 3.1 核心思想

**交易行为是人性博弈**：
- 价格运动的本质是人类情绪（贪婪、恐惧）的集体表达
- 情绪是动态变化的，需要**高阶导数**（加速度、加加速度）捕捉转折点
- 短期价格运动（15-120分钟）主要由**技术性因素**驱动：止损触发、突破追单、超买超卖反转

**关键洞察**（来自 v1 数据验证）：
- atr14_1m 与成功率强相关（低波动 5% vs 高波动 37.7%）
- 微观波动率是"行情启动"的领先指标，不是噪音
- 价格运动的主要阶段发生在预测窗口的前 50-60%

### 3.2 时间尺度匹配原则

**核心原则**：特征的时间尺度应该与预测窗口匹配

| 预测窗口 | 主要运动时间 | 核心特征尺度 | 辅助特征尺度 | 背景特征尺度 |
|---------|------------|------------|------------|------------|
| M15 (15分钟) | ~9 分钟 | **3m (40%), 5m (30%)** | 1m (10%), 15m (10%) | 1h (10%) |
| M30 (30分钟) | ~18 分钟 | **5m (30%), 15m (40%)** | 3m (10%), 1h (10%) | 4h (10%) |
| H1 (60分钟) | ~30 分钟 | **15m (30%), 1h (40%)** | 5m (10%), 4h (10%) | 日线 (10%) |
| H2 (120分钟) | ~72 分钟 | **1h (30%), 4h (40%)** | 15m (10%), 日线 (10%) | 周线 (10%) |

**设计逻辑**：
- **核心特征（60-70%）**：与预测窗口同尺度或稍长，捕捉主要价格运动
- **辅助特征（20-30%）**：更短的时间尺度捕捉启动信号，更长的时间尺度提供趋势背景
- **背景特征（10%）**：宏观趋势（牛市/熊市），影响短期概率分布

**关键修正**：
- 加入 **3m 时间尺度**（v1 没有）
  - 填补 1m-5m 之间的 5 倍跳跃
  - 对 M15 预测最关键（9 分钟 = 3 个 3m K 线）
  - 比 1m 更稳定，比 5m 更敏感

### 3.3 特征类别设计

#### 类别 1：价格加速度特征（核心）

**一阶（速度）**：
- `roc_1/3/5_{tf}` - 价格变化率（1/3/5 周期）
- `momentum_{tf}` - 动量

**二阶（加速度）**：
- `price_accel_{tf}` - 价格加速度
- `consecutive_accel_{tf}` - 连续加速 K 线数
- `accel_to_decel_{tf}` - 加速转减速信号

**三阶（加加速度/Jerk）**：
- `price_jerk_{tf}` - 价格加加速度
- `momentum_shift_{tf}` - 动量转折点

**心理学解释**：
- 加速度 > 0 → 贪婪情绪升温 → 追涨
- 加速度转负 → 贪婪冷却 → 即将反转

#### 类别 2：成交量加速度特征

**一阶**：
- `vol_roc_{tf}` - 成交量变化率
- `avg_trade_size_{tf}` - 单笔平均成交量（大单指标）

**二阶**：
- `vol_accel_{tf}` - 成交量加速度
- `vol_surge_intensity_{tf}` - 成交量爆发强度
- `large_order_accel_{tf}` - 大单加速度

**三阶**：
- `vol_jerk_{tf}` - 成交量加加速度
- `vol_decay_rate_{tf}` - 成交量衰减速度

**心理学解释**：
- 成交量爆发 → 大量散户涌入 → 情绪传染
- 成交量快速衰减 → 追涨资金耗尽 → 即将回调
- 大单突然增加 → 巨鲸入场 → 领袖效应

#### 类别 3：波动率加速度特征

**一阶**：
- `atr14_{tf}` - 平均真实波幅
- `bb_width_{tf}` - 布林带宽度
- `range_{tf}` - 振幅

**二阶**：
- `atr_accel_{tf}` - ATR 加速度
- `bb_width_accel_{tf}` - 布林带宽度加速度
- `volatility_explosion_{tf}` - 波动率爆炸指数

**心理学解释**：
- 波动率突然扩张 → 市场恐慌或狂热
- 波动率加速扩张 → 情绪失控 → 极端行情

#### 类别 4：买卖力量加速度特征

**一阶**：
- `taker_buy_ratio_{tf}` - 主动买入占比
- `buy_volume_{tf}` - 买入成交量

**二阶**：
- `buy_pressure_accel_{tf}` - 买入力量加速度
- `sell_pressure_accel_{tf}` - 卖出压力加速度
- `buy_sell_imbalance_accel_{tf}` - 买卖不平衡加速度

**心理学解释**：
- 主动买入加速 → 追涨情绪升温
- 主动买入减速 → 追涨资金耗尽 → 反转

#### 类别 5：技术指标加速度特征

**一阶**：
- `rsi14_{tf}` - RSI
- `macd_hist_{tf}` - MACD 柱状图
- `bb_position_{tf}` - 布林带位置
- `ema_cross_{tf}` - 均线交叉

**二阶**：
- `rsi_accel_{tf}` - RSI 加速度
- `macd_hist_accel_{tf}` - MACD 加速度
- `bb_position_accel_{tf}` - 布林带位置加速度
- `overbought_accel_{tf}` - 超买加速
- `overbought_exhaustion_{tf}` - 超买衰竭

**心理学解释**：
- RSI > 70 且加速 → 贪婪失控 → 即将见顶
- RSI > 80 但减速 → 追涨耗尽 → 反转信号

#### 类别 6：多周期共振特征

**跨时间尺度**：
- `accel_resonance_1m_3m_5m` - 1/3/5m 加速度共振
- `accel_divergence_1m_5m` - 1m vs 5m 加速度背离
- `vol_accel_resonance_{tf1}_{tf2}` - 成交量加速度共振
- `multi_tf_momentum_shift` - 多周期动量转折

**心理学解释**：
- 多周期共振 → 所有参与者同向 → 趋势强劲
- 加速度背离 → 短期冲动 vs 长期疲软 → 假突破

### 3.4 特征数量估算

每个模型约 **100-120 个特征**：

| 模型 | 1m | 3m | 5m | 15m | 1h | 4h | 日线 | 周线 | 共振 | 总计 |
|-----|----|----|----|----|----|----|-----|-----|-----|-----|
| M15 | 5 | 40 | 30 | 10 | 10 | 0 | 0 | 0 | 10 | **105** |
| M30 | 0 | 10 | 30 | 40 | 15 | 5 | 0 | 0 | 10 | **110** |
| H1 | 0 | 0 | 10 | 30 | 40 | 15 | 5 | 0 | 10 | **110** |
| H2 | 0 | 0 | 0 | 10 | 30 | 40 | 15 | 5 | 10 | **110** |

**设计原则**：
- 不是"越多越好"，而是"精准匹配"
- 控制特征数量避免维度灾难
- 每个时间尺度包含：基础指标 + 一阶导数 + 二阶导数

## 四、数据准备

### 4.1 需要下载的数据

**新增时间尺度**：
- **3m K 线**（币安支持，v1 没有）

**已有时间尺度**：
- 1m, 5m, 15m, 1h, 4h（v1 已有）

**需要补充**（如果做 H2 模型）：
- 日线（1d）
- 周线（1w）

### 4.2 特征计算流程

```
1. 下载原始 K 线数据
   ├─ 1m, 3m, 5m, 15m, 1h, 4h, 1d, 1w
   └─ 时间范围：2021-01-01 至今

2. 为每个时间尺度计算基础指标
   ├─ 价格类：ROC, EMA, MACD, BB
   ├─ 成交量类：VOL_ROC, AVG_TRADE_SIZE, TAKER_BUY_RATIO
   ├─ 波动率类：ATR, BB_WIDTH, RANGE
   └─ 技术指标：RSI, MACD_HIST, BB_POSITION

3. 计算高阶导数
   ├─ 一阶导数（变化率）
   ├─ 二阶导数（加速度）
   └─ 三阶导数（加加速度）

4. 计算多周期共振特征
   └─ 跨时间尺度的加速度共振和背离

5. 合并到 1 分钟时间轴
   └─ 所有特征对齐到 1 分钟 K 线的时间戳

6. 计算标签
   └─ 为每个（时间窗口 × 阈值）组合生成 y_long 和 y_short

7. 保存为 Parquet 文件
   └─ data/processed/multi_horizon/features_{horizon}m_thr{threshold}_{direction}.parquet
```

## 五、训练策略

### 5.1 Walk-forward 验证

复用 v1 的 Walk-forward 策略：
- **6 折交叉验证**
- **验证窗口**：4 个月
- **间隔**：5 天（避免数据泄露）

### 5.2 样本平衡

**问题**：正样本占比 10-15%，负样本 85-90%，不平衡

**解决方案**：
```python
# 方案 A：类别权重
class_weight = {
    0: 1.0,
    1: (负样本数 / 正样本数)
}

# 方案 B：下采样负样本
# 保留所有正样本，随机采样负样本使比例达到 1:2 或 1:3

# 方案 C：SMOTE（合成少数类过采样）
# 为正样本生成合成样本
```

**推荐**：先用方案 A（类别权重），简单有效

### 5.3 模型架构

**复用 v1 的 XGBoost 3-head**：
```python
# Head 1: 分类器（预测 y_class）
classifier = XGBClassifier(
    n_estimators=500,
    max_depth=6,
    learning_rate=0.05,
    subsample=0.8,
    colsample_bytree=0.8,
    scale_pos_weight=class_weight[1],
)

# Head 2: 回归器（预测 y_max，在全部样本上训练）
regressor_max = XGBRegressor(...)

# Head 3: 回归器（预测 y_min，在全部样本上训练）
regressor_min = XGBRegressor(...)

# Platt 校准
calibrator = LogisticRegression()
calibrated_proba = calibrator.predict_proba(classifier_scores)
```

### 5.4 超参数搜索

**第一阶段**：使用 v1 的默认参数，快速验证可行性

**第二阶段**（如果第一阶段成功）：
- 网格搜索或贝叶斯优化
- 调整：`max_depth`, `learning_rate`, `n_estimators`, `subsample`

## 六、实验计划

### 6.1 阶段 1：基线验证（优先）

**目标**：验证多时间窗口预测的可行性

**实验**：
1. 只训练 **M30 + 0.8% 阈值**（对应 v1 的设置）
2. 使用 v1 的特征（1m/5m/15m/1h/4h，不加 3m）
3. 对比 v1 的结果，验证流程正确性

**预期**：准确率应该与 v1 接近（~78%）

### 6.2 阶段 2：时间窗口对比

**目标**：找出最优的预测窗口

**实验**：
- 训练 M15/M30/H1/H2，每个用推荐阈值
- 使用 v1 的特征（不加 3m）
- 对比 4 个模型的准确率

**预期**：M15 和 M30 准确率最高

### 6.3 阶段 3：加入 3m 特征

**目标**：验证 3m 特征的价值

**实验**：
- 为 M15 和 M30 加入 3m 特征
- 对比加入前后的准确率提升

**预期**：M15 准确率提升明显（5-10%）

### 6.4 阶段 4：高阶特征验证

**目标**：验证加速度特征的价值

**实验**：
- 为最优模型（可能是 M15）加入高阶特征
- 对比基础特征 vs 基础+加速度特征

**预期**：准确率提升 3-5%

### 6.5 阶段 5：阈值优化

**目标**：找出每个时间窗口的最优阈值

**实验**：
- 为每个时间窗口训练 3 个不同阈值的模型
- 对比准确率和 F1 分数

**预期**：找到最优阈值组合

## 七、成功标准

### 7.1 最低标准（可行性验证）

- 任意一个模型的准确率 **> 60%**
- 精确率 **> 50%**（预测为正时，一半以上是对的）
- 召回率 **> 40%**（实际为正时，能预测出 40%）

### 7.2 目标标准（值得继续优化）

- 最优模型准确率 **> 70%**
- F1 分数 **> 0.6**
- ROC-AUC **> 0.75**

### 7.3 优秀标准（可以进入交易策略阶段）

- 最优模型准确率 **> 75%**
- 精确率 **> 70%**
- 召回率 **> 60%**
- F1 分数 **> 0.65**

## 九、风险与挑战

### 9.1 技术风险

**风险 1：3m 数据质量**
- 币安 3m K 线可能有缺失或错误
- **缓解**：下载后验证完整性，与 1m 数据对比

**风险 2：特征过多导致过拟合**
- 100+ 特征可能过拟合
- **缓解**：使用 Walk-forward 验证，监控训练集 vs 验证集差异

**风险 3：计算成本**
- 更多时间尺度 = 更多计算时间
- **缓解**：先用小数据集验证，再全量训练

### 9.2 模型风险

**风险 1：短期预测可能是随机的**
- 15 分钟内的价格运动可能无法预测
- **缓解**：如果准确率 < 60%，说明不可预测，及时止损

**风险 2：不同市场状态下表现差异大**
- 牛市 vs 熊市 vs 震荡市
- **缓解**：分市场状态评估，必要时训练多个模型

## 十、总结

### 10.1 核心创新点

1. **多时间窗口对比**：找出最可预测的时间尺度
2. **加入 3m 特征**：填补 1m-5m 空白，对短期预测关键
3. **高阶特征（加速度）**：捕捉情绪转折点，基于人性博弈
4. **数据驱动的阈值选择**：不拍脑袋，用数据说话

### 10.2 与 v1 的区别

| 维度 | v1 | 多时间窗口模型 |
|-----|----|-----------| 
| 预测窗口 | 固定 30 分钟 | 4 个窗口（15/30/60/120 分钟） |
| 时间尺度 | 1m/5m/15m/1h/4h | 加入 3m，H2 加入日线/周线 |
| 特征类型 | 基础技术指标 | 基础 + 高阶导数（加速度） |
| 阈值 | 固定 1.0% | 多阈值实验（0.3%-2.0%） |
| 目标 | 交易盈利 | 预测准确率（第一阶段） |

### 10.3 预期成果

**最低成果**：
- 验证多时间窗口预测的可行性
- 找出最优的预测窗口和阈值组合

**理想成果**：
- 找到准确率 > 75% 的模型
- 为下一阶段（交易策略设计）提供可靠的预测模型
