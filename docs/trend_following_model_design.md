# 趋势跟踪模型设计方案

## 一、设计目标

捕捉中长期趋势行情（数小时到数天），在低波动期也能盈利。

**与 v1 的核心区别**：
- v1：预测"30分钟内能否快速波动0.8%"（高频短期）
- 趋势模型：预测"趋势是否启动并持续"（低频中长期）

**典型场景**：
- 2天内价格从 2298 → 2351（2.3%），但每小时只涨0.5%
- v1 判断"30分钟内不够0.8%" → 不触发
- 趋势模型判断"趋势启动" → 入场并持有到趋势结束

## 二、人性博弈视角的止盈止损设计

### 2.1 传统技术分析的陷阱

**常见做法**（容易被猎杀）：
```
止损：跌破 EMA20
止盈：ATR trailing stop
```

**问题**：
1. **EMA20 是公开指标** → 所有人都看得到 → 庄家知道散户的止损位
2. **猎杀止损**：故意打穿 EMA20 触发止损，然后价格立刻反弹
3. **假突破**：短暂跌破支撑位，收集止损单，再拉回去

**真实案例**：
- 价格在 2350 附近震荡，EMA20 在 2345
- 突然快速下跌到 2343（跌破 EMA20）
- 散户止损离场
- 5分钟后价格回到 2350，继续上涨到 2360
- 散户：被"扫损"了

### 2.2 反猎杀止损策略

**核心思想**：不用公开技术指标，用"行为模式"判断真假突破

#### 策略 1：时间 + 幅度双重确认

**不是**：跌破 EMA20 立刻止损  
**而是**：跌破 EMA20 **且持续 N 分钟** 才止损

```python
# 假突破特征：
# - 快速跌破（1-2根K线）
# - 立刻反弹（5分钟内）
# - 成交量不大（没有真实抛压）

# 真突破特征：
# - 持续下跌（连续3根以上K线）
# - 不反弹（15分钟内不回到支撑位上方）
# - 成交量放大（真实抛盘）

止损条件 = (
    价格 < 入场价 * 0.99  # 回撤1%
    AND 持续时间 >= 15分钟  # 不是瞬间插针
    AND 最低价 < 入场价 * 0.985  # 确实跌破了，不是擦边
)
```

**人性解读**：
- 庄家猎杀止损：快进快出（1-5分钟）
- 真实趋势反转：持续下跌（15分钟+）

#### 策略 2：成交量确认

**不是**：只看价格跌破  
**而是**：价格跌破 **且成交量放大**

```python
# 假突破：
# - 价格跌破支撑位
# - 但成交量很小（庄家自己对倒）
# - 目的：触发散户止损单

# 真突破：
# - 价格跌破支撑位
# - 成交量明显放大（真实抛盘）
# - 说明：大量持仓者真的在卖出

止损条件 = (
    价格 < 入场价 * 0.99
    AND 当前5分钟成交量 > 过去20根K线平均成交量 * 1.5
    AND 主动卖出占比 > 60%  # taker_sell_ratio
)
```

**人性解读**：
- 庄家猎杀：小成交量（自己玩）
- 真实恐慌：大成交量（散户真的在逃）

#### 策略 3：多层止损（不是一刀切）

**不是**：触发止损 → 全部平仓  
**而是**：分层止损，给趋势"喘息空间"

```python
# 第一层：警戒线（不平仓，只警告）
if 价格 < 入场价 * 0.995:  # 回撤 0.5%
    状态 = "警戒"
    # 不平仓，但停止加仓

# 第二层：减仓线（平50%）
if 价格 < 入场价 * 0.99 AND 持续10分钟:
    平仓 50%
    # 保留一半仓位，防止假突破

# 第三层：止损线（全平）
if 价格 < 入场价 * 0.985 AND 持续15分钟:
    平仓 100%
    # 确认趋势反转
```

**人性解读**：
- 趋势不是直线，会有回调
- 给趋势"犯错空间"，不要一碰就跑
- 但如果持续下跌，果断离场

#### 策略 4：反向确认（最狡猾的）

**核心**：不看"跌破了什么"，而看"跌破后的反应"

```python
# 场景：价格跌破 EMA20（2345）到 2343

# 假突破判断：
if 跌破后5分钟内:
    if 价格回到 2345 以上:
        # 这是假突破，庄家猎杀
        # 不止损，继续持有
        pass

# 真突破判断：
if 跌破后15分钟内:
    if 价格持续在 2343 以下:
        # 这是真突破
        # 止损离场
        平仓()
```

**人性解读**：
- 假突破：庄家急着拉回去（怕散户发现）
- 真突破：价格持续低迷（真的没人买）

### 2.3 止盈策略（不贪婪，但也不被吓跑）

#### 策略 1：分批止盈

**不是**：涨到目标位 → 全部平仓  
**而是**：分批止盈，让利润奔跑

```python
# 第一批：保本止盈（涨1%时平30%）
if 价格 >= 入场价 * 1.01:
    平仓 30%
    # 锁定部分利润，心理安全

# 第二批：目标止盈（涨2%时平40%）
if 价格 >= 入场价 * 1.02:
    平仓 40%
    # 达到预期目标

# 第三批：跟踪止盈（剩余30%用动态止盈）
if 价格 >= 入场价 * 1.02:
    跟踪止损 = max(跟踪止损, 当前价 * 0.99)
    # 让利润奔跑，但保护已有收益
```

**人性解读**：
- 人性：怕利润回吐 → 过早止盈
- 对策：先平一部分（心理安全），剩余的让它跑

#### 策略 2：动态目标（根据波动率调整）

**不是**：固定目标 2%  
**而是**：根据市场波动率动态调整

```python
# 高波动期（ATR > 1.5%）
目标止盈 = 入场价 * 1.03  # 3%

# 中波动期（ATR 0.8-1.5%）
目标止盈 = 入场价 * 1.02  # 2%

# 低波动期（ATR < 0.8%）
目标止盈 = 入场价 * 1.015  # 1.5%
```

**人性解读**：
- 高波动：市场情绪激烈，可以多拿一会儿
- 低波动：市场冷淡，见好就收

#### 策略 3：时间止盈（防止无限持仓）

**不是**：只要不止损就一直拿着  
**而是**：超过一定时间，即使盈利也平仓

```python
# 最大持仓时间：48小时
if 持仓时间 > 48小时:
    if 当前盈利 > 0:
        平仓()  # 盈利了就走
    else:
        # 亏损但时间到了，也要考虑离场
        if 当前亏损 < 0.5%:
            平仓()  # 小亏离场，不等了
```

**人性解读**：
- 趋势模型不是"永久持仓"
- 如果48小时都没涨，说明判断错了
- 及时离场，寻找下一个机会

## 三、标签设计（基于人性的趋势定义）

### 3.1 什么是"真趋势"？

**不是**：未来N小时涨X%  
**而是**：启动后持续上涨，中间回调不超过阈值

```python
# 真趋势特征：
# 1. 最终涨幅 >= 2%
# 2. 中间最大回撤 < 1%（不是来回震荡）
# 3. 达到时间 <= 48小时
# 4. 上涨过程中没有"假突破"（快速反转）

def is_true_trend(future_prices, entry_price):
    max_gain = (future_prices.max() - entry_price) / entry_price
    
    # 条件1：最终涨幅够
    if max_gain < 0.02:
        return False
    
    # 条件2：中间回撤不大（趋势稳定）
    max_drawdown = 0
    peak = entry_price
    for price in future_prices:
        if price > peak:
            peak = price
        dd = (peak - price) / peak
        max_drawdown = max(max_drawdown, dd)
    
    if max_drawdown > 0.01:  # 回撤超过1%
        return False
    
    # 条件3：时间窗口
    if len(future_prices) > 576:  # 48小时 = 576个5分钟K线
        return False
    
    return True
```

### 3.2 标签定义

```python
# 主标签：是否是真趋势
y_trend = 1 if is_true_trend(...) else 0

# 辅助标签（用于回归预测）
y_max_gain = 最大涨幅（%）
y_duration = 趋势持续时间（小时）
y_max_drawdown = 中间最大回撤（%）
```

### 3.3 负样本定义（什么不是趋势）

```python
# 负样本类型1：震荡（来回波动）
# - 涨了又跌，跌了又涨
# - 最终涨幅 < 2% 或 中间回撤 > 1%

# 负样本类型2：假突破
# - 快速上涨1%，然后立刻回落
# - 这是"诱多"，不是真趋势

# 负样本类型3：慢涨但时间太长
# - 48小时才涨2%
# - 资金效率太低，不值得持有
```

## 四、特征工程（捕捉趋势启动信号）

### 4.1 趋势强度特征

**目标**：判断"这是趋势启动，不是震荡"

```python
# 1. EMA斜率（趋势方向）
ema_slope_1h = (ema20_1h[-1] - ema20_1h[-5]) / ema20_1h[-5]
# 正值且增大 → 上升趋势

# 2. 价格相对EMA位置
price_above_ema = (price - ema20_1h) / ema20_1h
# > 0 且持续 → 趋势确立

# 3. 多周期EMA共振
ema_resonance = (
    (ema9_5m > ema21_5m) and
    (ema9_15m > ema21_15m) and
    (ema9_1h > ema21_1h)
)
# 多周期同向 → 趋势强劲

# 4. ADX（趋势强度指标）
adx_1h = ...  # > 25 表示有趋势（不管涨跌）
```

### 4.2 动量持续性特征

**目标**：判断"这个趋势能持续，不是昙花一现"

```python
# 1. 连续上涨K线数
consecutive_up_bars = ...
# >= 3 → 动量持续

# 2. 动量加速度
momentum_accel = roc5_5m[-1] - roc5_5m[-3]
# > 0 → 加速上涨

# 3. 成交量趋势
volume_trend = (volume_5m[-5:].mean() / volume_5m[-20:-5].mean())
# > 1.2 → 成交量放大，趋势有支撑

# 4. 主动买入持续性
taker_buy_ratio_avg = taker_buy_ratio_5m[-5:].mean()
# > 0.55 → 持续有人追涨
```

### 4.3 反猎杀特征（识别假突破）

**目标**：避免在"诱多"时入场

```python
# 1. 快速拉升后的回调
rapid_pump = (price - price_10m_ago) / price_10m_ago > 0.01
recent_pullback = (price_5m_high - price) / price_5m_high > 0.003
if rapid_pump and recent_pullback:
    # 可能是诱多后的回调，不是真趋势启动
    is_fake_breakout = 1

# 2. 成交量异常（对倒）
volume_spike = volume_5m[-1] / volume_5m[-20:].mean() > 3
price_change_small = abs(price - price_5m_ago) / price < 0.002
if volume_spike and price_change_small:
    # 成交量大但价格不动 → 对倒
    is_manipulation = 1

# 3. 跌破后快速拉回（猎杀止损）
broke_support = price_5m_low < ema20_5m
quick_recovery = price > ema20_5m
if broke_support and quick_recovery:
    # 这是猎杀止损，不是真突破
    is_stop_hunt = 1
```

### 4.4 宏观背景特征

**目标**：判断"大环境支持趋势"

```python
# 1. 日线趋势
daily_trend = (ema9_1d > ema21_1d)
# 日线上升 → 短期趋势更容易成功

# 2. 资金费率趋势
funding_rate_trend = funding_rate_8h[-3:].mean()
# 正值且上升 → 多头情绪强

# 3. 波动率状态
atr_regime = atr14_1h / atr14_1h[-20:].mean()
# > 1.2 → 波动率扩张，趋势容易启动

# 4. 距离关键价位
distance_to_resistance = (resistance_level - price) / price
# > 0.02 → 上方空间足够，不会立刻遇阻
```

## 五、模型架构

### 5.1 三阶段模型

**不是**：一个模型预测所有  
**而是**：三个模型分工合作

```python
# 模型1：趋势启动分类器
# 输入：当前市场特征
# 输出：P(趋势启动) ∈ [0, 1]
# 阈值：0.65（比v1的0.60更严格）

# 模型2：目标涨幅回归器
# 输入：当前市场特征
# 输出：预期最大涨幅（%）
# 用途：动态调整止盈目标

# 模型3：持续时间回归器
# 输入：当前市场特征
# 输出：预期趋势持续时间（小时）
# 用途：动态调整最大持仓时间
```

### 5.2 训练策略

**Walk-forward 验证**（复用v1）：
- 6折交叉验证
- 验证窗口：4个月
- 间隔：5天

**样本平衡**：
- 正样本（真趋势）：预计 5-10%
- 负样本：90-95%
- 使用类别权重平衡

**评估指标**：
- 准确率 > 70%
- 精确率 > 65%（预测为趋势时，65%是对的）
- 召回率 > 50%（真趋势中，能抓住50%）

## 七、风险与挑战

### 7.1 技术风险

**风险1：真趋势太少**
- 如果一年只有10次真趋势，样本不够训练
- **缓解**：降低阈值（1.5%涨幅也算），增加样本

**风险2：止损策略过于复杂**
- 多层止损、时间确认 → 实盘执行困难
- **缓解**：先用简单策略，逐步优化

**风险3：过拟合历史数据**
- 反猎杀策略基于历史模式，未来可能失效
- **缓解**：Walk-forward 验证，定期重新训练

### 7.2 心理风险

**风险1：趋势模型信号少，容易焦虑**
- 可能一周才1-2次信号
- **缓解**：同时运行v1（高频）和趋势模型（低频）

**风险2：持仓时间长，心理压力大**
- 持仓24小时，中间会有回调
- **缓解**：分批止盈，降低心理负担

## 九、成功标准

### 9.1 最低标准（可行性验证）

- 真趋势识别准确率 > 60%
- 年化信号频率 > 50 次（平均每周1次）
- 平均单次盈利 > 1.5%

### 9.2 目标标准（值得投入）

- 真趋势识别准确率 > 70%
- 精确率 > 65%（减少假信号）
- 平均单次盈利 > 2%
- 最大持仓时间 < 48 小时

### 9.3 优秀标准（可以作为主力策略）

- 真趋势识别准确率 > 75%
- 精确率 > 70%
- 平均单次盈利 > 2.5%
- 年化收益 > v1
