## 三、核心问题分析

### 问题 1：13:xx 时段成为系统性死区（全周期 0/17）

本轮数据将 13:xx 的信号数从 8 个扩大到 17 个，胜率仍然 **0%**，且是整个分析期最惨烈的单小时时段。

```
时段     信号数    TP    SL    胜率
13:xx     17       0    17    0.0%
```

最新案例：05-04 13:25–13:55 连续 7 个 LONG 信号（1h=DN，−0.4%~−0.7%），全部被扫损。行情背景：美东时间下午 1 点，亚洲收盘、欧美开盘交接，日内下跌趋势已形成，模型连续抄底直至全灭，与 04-27 13:xx 场景几乎完全重复。

**13:xx 是北京时间下午1点（UTC+8），对应的是亚洲尾盘 + 欧洲开盘的方向确立期。一旦趋势向下，这个时间段的「超卖」信号没有任何反转支撑。**

### 问题 2：07:xx 新暴露死区（0/7）

前报未识别（信号量不足），本轮扩展后确认：

```
时段     信号数    TP    SL    胜率
07:xx     7        0     7    0.0%
```

05-04 07:25–07:55 连续 6 个 LONG（1h=DN），全部 SL。这个时段是北京时间上午 7 点（UTC+8），对应 UTC 23:xx——深夜亚洲低流动性尾盘，价格随机游走，逆势信号完全无效。

### 问题 3：Cascade 胜率暴降（28.6% vs 独立信号 56.2%）

| 类型 | 信号数 | 已解仓 | 胜率 |
|------|--------|--------|------|
| Cascade 信号 | 63 | 42 | **28.6%** |
| 独立信号 | 46 | 32 | **56.2%** |

本轮新增两次毁灭性 Cascade：

- **05-04 07:25–07:55 LONG×6**（1h=DN）：0 TP / 6 SL，进场价 2294–2312，被跌至 2265 区域全扫
- **05-04 13:25–13:55 LONG×7**（1h=DN）：0 TP / 5 SL / 2 OPEN，下跌趋势中连续抄底

加上已有的 04-27 13:xx（0/8）、04-27 22:xx–23:xx（1/7）、05-01 22:xx（0/7），Cascade 类型中逆 1h 趋势的批次几乎没有成功案例。

### 问题 4：R>2x 高 R-ratio 信号胜率极低

R > 2.0x 的信号集中在波动极大的市场环境（止损距离远），这类信号通常处于趋势强烈运行中，逆势做多/空几乎不可能成功。应加入最高 R-ratio 限制（建议 ≤ 2.0x）。

### 问题 5：FLAT 趋势 Cascade 仍持续

05-01 22:10–22:55 LONG×7（1h=FL）：0 TP / 3 SL / 4 OPEN（最终全部亏损）。在 1h 趋势为震荡时，连续多头信号依然成批触发且整体失败。

### 优先级 1：时段封闭（立即可执行，无需重训）

封闭 13:xx 和 07:xx 两个时段，可减少 24 个无效信号（均为 SL），预计将整体胜率从 38.5% 提升至约 44%。

### 优先级 2：R-ratio 上限（≤ 2.0x）

R > 2x 的 26 个信号胜率仅 22.7%（6/26），去掉后全部样本胜率升约 +2pp，同时避免大止损比的风险。

```python
if r_ratio > 2.0:
    skip()  # 仅在非极端超卖场景下过滤
```

### 优先级 3：FLAT 对齐 + 连续信号冷却

- 1h=FL 且已是同方向第 2 个以上连续信号时：跳过
- 同方向连续发 ≥3 个信号后，强制 30min 冷却期

这两条规则可消除大部分 Cascade 亏损场景。

### 优先级 4（中期）：13:xx 和 07:xx 特征工程

将时段特征（`hour_of_day` 已在 rank 13/137）的权重针对性增强，或在训练数据中为这两个时段构建专门的 label 标注（空仓 label），让模型直接学会在这些时段保守。

## 六、结论

v1 模型在 9.6 天的扩展周期内共触发 109 个信号，真实胜率 38.5%，期望值 **−0.144R/笔**，较前报（−0.045R）明显恶化。核心原因是扩展期内出现了两次新的系统性失败模式：07:xx 全灭和 05-04 双 Cascade（13:xx + 07:xx），均在顺下跌趋势中重复了 04-27 13:xx 的失败逻辑。

**有效模式（需保留）**：
- 02:xx 时段（胜率 77.8%）
- 超卖扩展后反转（>0.8% 跌幅后，胜率 50% vs 普通 35%）
- 09:xx 顺势 LONG（57%）

**失效模式（需屏蔽）**：
- 13:xx 时段（0/17，历史累计 0%）
- 07:xx 时段（0/7）
- Cascade 中逆 1h 趋势的批次（<20%）

**无需重训的短期修复预期提升**：封闭 13:xx + 07:xx + R>2x 过滤 → 预计胜率恢复至 44–48%，接近盈亏平衡。
