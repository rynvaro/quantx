## 三、核心问题分析

### 问题 1：初期正 EV 是幸存者偏差，扩展后彻底反转

| 分析时段 | 信号数 | 真实胜率 | EV/笔 |
|---------|--------|--------|-------|
| Apr 29–30（30.9h，前报） | 27 | 51.9% | **+0.108R** |
| Apr 29 – May 04（135.4h，本报） | 65 | 36.9% | **−0.197R** |

前报 27 个信号的运行期间恰好覆盖了 04-30 02:xx 的极端超卖反弹（ETH 2238 低点），这一事件贡献了大量 TP（7/9）。扩展后新增的 38 个信号中：

- TP = 7，SL = 23，OPEN = 8（已解 31，胜率仅 22.6%）

新增信号质量极差，集中在 05-01 22:xx（FLAT Cascade，0/7）、05-04 07:xx 和 13:xx（DN Cascade，均全败），印证了超卖反弹场景消失后模型没有持续 alpha。

### 问题 2：FLAT 趋势下全面崩溃（胜率 11.8%）

按 1h 趋势对齐分类（全解仓）：

| 趋势对齐 | 信号数 | 胜率 |
|---------|--------|------|
| WITH（顺势） | 10 | **30.0%** |
| **FLAT（震荡）** | 17 | **11.8%** ← 极差 |
| AGST（逆势） | 38 | **50.0%** ✓ |

FLAT 环境 17 个信号只有 2 TP，且：
- 04-30 02:05 LONG（FL，SL）— 已在前报分析
- 04-30 21:50–21:55 LONG×2（FL，全 SL）
- 05-01 22:10–22:55 LONG×7（FL，全 SL）
- 05-03 07:45 LONG（FL，SL）

05-01 22:xx 是最新一轮 FLAT Cascade（7个信号，1h=FL，0 TP / 3 SL / 4 OPEN，最终全败），与 04-30 03:xx SHORT Cascade 性质相同——在趋势不明确时连续触发并全灭。

### 问题 3：SHORT 胜率 22.2%，无实盘价值

| 统计 | 数值 |
|------|------|
| SHORT 信号总数 | 18 |
| 真实 TP（24h） | 4 |
| 真实 SL（24h） | 14 |
| 全解仓胜率 | **22.2%** |

唯一有效的 SHORT 场景：04-29 23:25（1h=DN，WITH，TP +3bar）和 05-04 06:15、09:35（UP 逆势超买后回落，各 TP +1bar）。其余 15 个 SHORT 全部失败，包括整个 04-30 03:50–08:40 时段（5 个 SHORT Cascade，全失败）。

### 问题 4：同一失败模式在 05-04 重演

```
05-04 07:25–07:55  LONG×3  (1h=DN, −0.5%)  →  0 TP / 3 SL  07:xx 死区
05-04 13:30–13:55  LONG×4  (1h=DN, −0.5%)  →  0 TP / 3 SL / 1 OPEN  13:xx 死区
```

v1.0.1 在新周期内重复了与 v1 完全相同的失败模式，说明两版本在时间段敏感性上无本质差异，07:xx 和 13:xx 对两模型都是系统性盲区。

### 问题 5：R > 1.5x 区间胜率极低

| R 段 | 信号数 | 胜率 |
|------|--------|------|
| < 1.0x | 16 | **75.0%** |
| 1.0–1.5x | 14 | 35.7% |
| 1.5–2.0x | 19 | **15.8%** |
| 2.0–3.0x | 14 | 28.6% |
| 3.0x+ | 2 | 0.0% |

R < 1.0x 的 75% 胜率与前报一致，是 v1.0.1 持续有效的特征：这类信号在极端超卖时止损极近，进场精准，快速 TP。但 R > 1.5x 区间的 15.8% 胜率意味着模型在波动大的场景中几乎全败，是需要过滤的主要噪声来源。

## 五、改进建议

### 优先级 1：立即关闭 SHORT（最高优先）

SHORT 胜率 22.2%，继续实盘是持续亏损来源。建议在信号逻辑层完全屏蔽 SHORT 输出，直到 SHORT 方向的训练数据和特征经过专项审计。

**特例保留**：UP 过买（prior 1h > +0.8%）时的 SHORT——这类场景在本周期 2/2 成功，但需严格限定条件。

### 优先级 2：FLAT 趋势全面屏蔽（不限方向）

FLAT 信号胜率 11.8%（2/17），两个成功案例均有其他条件支撑（超卖或特殊时段）。建议：

```python
if trend_1h == "FL":
    skip()   # 无论 LONG 还是 SHORT
```

与 v1 合并：FLAT 过滤是两版本共同急需的修复。

### 优先级 3：时段封闭

与 v1 完全一致：
- **13:xx**：0/6（全解仓），强制关闭
- **07:xx**：0/5，强制关闭
- **03:xx–05:xx**：关闭或仅保留 LONG，且需要 overextension 条件

### 优先级 4：R-ratio 门控

- 过滤 R > 1.5x 的信号（胜率 15.8%，无贡献价值）
- 优先选择 R < 1.0x 场景（75% 胜率，特征明确）

### 优先级 5：专注「超卖扩展 LONG」模式

v1.0.1 在扩展期内唯一稳定有效的模式就是 overextension LONG（75%）。下一步特征工程应显式加入这个条件作为独立特征：

```python
# 候选特征
overext_long = (prior_1h_chg < -0.8)    # 1h 跌幅超 0.8%
tbr_reversal = (tbr_trend_15m > 0 and tbr_trend_5m > 0)  # 买方回升确认
# 信号发出条件: overext_long AND tbr_reversal AND direction == LONG
```

## 六、结论

v1.0.1 模型在 5.6 天完整周期内，65 个信号，真实胜率 36.9%，EV **−0.197R/笔**。前报（30.9h）的 +0.108R 正期望是极端市场事件（04-30 超卖反弹）造成的幸存者偏差，随样本扩大已完全消失。

**核心发现（与前报对比）**：
- 超卖扩展胜率（75%）**依然成立**——这是 `tbr_trend` 贡献的真实 alpha
- SHORT 胜率（22.2%）**持续恶化**，无实盘价值
- FLAT 趋势胜率（11.8%）**比 v1 更差**，需强制屏蔽
- 07:xx 和 13:xx 死区**两模型共享**，不是 v1 特有问题

**v1.0.1 vs v1 现状**：在去除共同的失败模式（死区时段、FLAT 信号）后，v1.0.1 的 LONG 逆势胜率（50%）仍优于 v1 同类信号（40%），说明 `tbr_trend` 特征在正确的场景下是有效的。关键是要让模型只在正确的场景下触发，而不是在所有场景下泛化触发。

**最小化修复路径**：SHORT 关闭 + FLAT 屏蔽 + 时段封闭 → 可将有效信号池压缩到约 15–20 个/5天，但这些信号的预期胜率将接近 55–60%。质量优于数量。
