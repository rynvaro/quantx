## 三、核心问题分析

### 问题 1：FLAT 趋势信号是最大拖累（胜率仅 21.4%）

全解仓分析中，按 1h 趋势对齐分类：

| 趋势对齐 | 信号数 | 胜率 |
|---------|--------|------|
| WITH（顺势） | 11 | **54.5%** |
| FLAT（震荡） | 14 | **21.4%** ← 主要失败 |
| AGST（逆势） | 38 | **50.0%** |

FLAT 环境下信号质量极差，3胜11负。具体来看，这类信号集中在两个时段：
- **04-30 02:05**：1h 趋势为 FL，模型不清楚方向就发 LONG，直接被扫（+1bar SL）
- **04-30 03:50–04:25**：4 个 SHORT 信号，1h=FL，全部 SL（见问题 3）

### 问题 2：04-27 13:20–13:55 逆势抄底 Cascade — 最严重事件

```
真实行情：2381 → 2322（急跌 2.5%，04-27 13:00 1h K 线 −2.53%）
模型行为：连续触发 8 个 LONG 信号，逆势做多
全部结果：0 TP / 2 SL / 6 OPEN（6个在 30min 内没有解仓，最终全部亏损）
1h 趋势：DN，模型完全无视
```

每个信号进场后价格路径：`▼▼▼▼▼▼`（全程下行）。模型在下跌趋势中连续抄底，核心原因：均值回归类特征（如短期 RSI 超卖、BB 下轨触碰）不断触发，而模型没有宏观趋势感知。

更严重的是：该 1h 跌幅对模型而言是「盲点」——模型的 LONG 概率在整个 1h 内最高仅 0.09，显示模型根本没有对应这种急跌的特征，却仍在低层特征的驱动下疯狂发多头信号。

### 问题 3：04-27 22:55–23:30 LONG Cascade — 下跌中的对抗

```
真实行情：2318 → 2267（再跌 2.2%，04-27 23:00 1h K 线 −1.74%）
模型行为：7 个 LONG 信号
结果：1 TP / 5 SL / 1 OPEN（胜率 17%）
```

区别于 13:xx 的「完全盲目」，23:xx 的信号中有 1 个 TP（23:25 LONG @ 2268，下跌到接近日内低点后成功弹起），说明模型在极端超卖点偶尔能抓到反弹，但精度不足，其余 5 个都被扫损。

### 问题 4：04-30 03:50–04:25 SHORT Cascade — 弹后追空

```
真实行情：02:00 ETH 跌至 2238 低点 → 03:30 起开始反弹至 2268
模型行为：4 个 SHORT 信号，追空反弹
结果：0 TP / 4 SL（100% 亏损）
1h 趋势：FL（价格在低位震荡，实际是向上恢复）
```

弹后追空是经典的「趋势误判」。市场刚从极端下跌中恢复，1h 趋势显示 FL，SHORT 信号在这种环境下毫无胜率。

### 问题 5：S2 形态效果极差

全解仓分析中 S2 形态（反弹失败做空）：1 TP / 6 SL = **14.3% 胜率**。与之前 R3 报告中 S2 胜率 100% 形成强烈反差，说明 S2 的有效性高度依赖市场环境（R3 期间多空均衡，本周期偏单边）。

### 优先级 3：废弃 S2 形态

### 优先级 4：最低 R-ratio 门控（≥ 1.2x）

R < 1.0x 的信号：41.4% 胜率，几乎无盈利价值。在信号发出前检查 `tp_pct / sl_pct < 1.2` 时直接跳过。

## 六、结论

v1 模型本轮运行 5.25 天，64 个信号，真实胜率 44.4%，期望值 **−0.045R/笔**（轻微负）。与 R3 分析（66.7% 胜率）相比有明显下降，核心原因是本周期包含多个单边行情（04-27 下午急跌、04-30 凌晨再跌），而 v1 模型在单边趋势中的逆势抄底行为未被改善。

本轮亮点：
- 顺势信号质量依然较好（WITH 胜率 54.5%）
- 极端超卖后的反弹捕捉能力有所体现（02:35–02:45 三连 TP）
- 02:xx 和 09:xx 时段信号质量突出

核心缺陷：
- FLAT 趋势环境信号胜率仅 21.4%
- 13:xx 和 03:xx–04:xx 两段时间窗口完全失效
- S2 形态本轮彻底失灵

**短期修复路径（无需重训）**：时间段关闭（13:xx, 03:xx–04:xx） + FLAT 趋势过滤 + 最低 R-ratio 门控，预计可将胜率提升至 50%+。
