# 加速前预测指标分析

## 一、核心问题

**当前问题**：加速度指标（roc_accel）有滞后性
- 识别出"正在加速"时，加速可能已经进行了一半
- 5分钟K线 → 滞后10-15分钟
- 错过最佳入场时机

**解决思路**：不看"加速度"（结果），看"加速的原因"（前置信号）

---

## 三、详细指标分析

### 3.1 成交量爆发（P0 - 最推荐）

**原理**：
- 价格加速 = 大量资金涌入
- 大量资金涌入 = 成交量放大
- **成交量放大先于价格加速**

**指标定义**：
```python
# 成交量爆发指数
vol_surge_1m = volume_1m / volume_1m_ma20
vol_surge_5m = volume_5m / volume_5m_ma20

# 触发条件
if vol_surge_1m > 2.0:  # 成交量是均值的2倍
    # 预测：即将加速
```

**实际意义**：
- vol_surge > 2.0 → 成交量突然翻倍
- 说明有大资金进场
- 通常发生在加速启动前1-3分钟

**案例分析（12:45大跌）**：
```
12:40-12:45  如果成交量突然放大2倍
           → 预警：可能即将加速下跌
12:45-12:50  价格开始加速下跌
           → 验证：成交量爆发是有效信号
```

**优势**：
- ✓ 领先时间：1-3分钟
- ✓ 可靠性：非常高（成交量不会骗人）
- ✓ 实现简单：当前数据就有
- ✓ 噪音低：成交量爆发不常见

**劣势**：
- ✗ 无法判断方向（只知道要加速，不知道涨跌）
- ✗ 需要结合价格趋势判断

---

### 3.2 主动买入占比突变（P0 - 最推荐）

**原理**：
- 主动买入 > 主动卖出 → 买方力量强 → 即将上涨
- 主动卖出 > 主动买入 → 卖方力量强 → 即将下跌
- **订单流先于价格变化**

**指标定义**：
```python
# 主动买入占比
taker_buy_ratio = taker_buy_volume / total_volume

# 主动买入占比加速度
tbr_accel_1m = taker_buy_ratio_1m - taker_buy_ratio_1m_lag5

# 触发条件
if tbr_accel_1m > 0.1:  # 主动买入占比突然增加10%
    # 预测：即将加速上涨
elif tbr_accel_1m < -0.1:  # 主动买入占比突然减少10%
    # 预测：即将加速下跌
```

**实际意义**：
- taker_buy_ratio 从 50% 跳到 70%
- 说明买方突然变强
- 通常发生在上涨加速前30秒-2分钟

**案例分析（12:45大跌）**：
```
12:40-12:45  如果taker_buy_ratio从50%跌到30%
           → 预警：卖方力量突然增强，可能加速下跌
12:45-12:50  价格开始加速下跌
           → 验证：订单流失衡是有效信号
```

**优势**：
- ✓ 领先时间：30秒-2分钟（最快）
- ✓ 可靠性：非常高（反映真实买卖意愿）
- ✓ 有方向性：可以判断涨跌
- ✓ 当前数据就有

**劣势**：
- ✗ 需要计算加速度（tbr_accel）
- ✗ 阈值需要调优

---

### 3.3 ATR压缩后扩张（P0 - 推荐）

**原理**：
- 加速 = 波动率扩张
- 波动率扩张前，通常有"压缩"阶段
- **波动率从压缩到扩张 = 加速启动**

**指标定义**：
```python
# ATR压缩比
atr_compression = atr14_1m / atr14_1m_ma20

# 状态判断
if atr_compression < 0.5:
    # 极度压缩（蓄力阶段）
    # 预测：即将波动率扩张（加速）
elif atr_compression > 1.5:
    # 正在扩张（加速中）
```

**实际意义**：
- atr_compression < 0.5 → 波动率是均值的一半
- 市场"安静"了很久
- 通常会有"爆发"（压缩后的释放）

**案例分析（12:45大跌）**：
```
12:00-12:40  如果ATR持续压缩（atr_compression < 0.5）
           → 预警：市场太安静，即将爆发
12:45-13:00  ATR突然扩张（atr_compression > 1.5）
           → 验证：压缩后的爆发
```

**优势**：
- ✓ 领先时间：5-15分钟
- ✓ 可靠性：高（压缩后必然释放）
- ✓ 实现简单：当前数据就有
- ✓ 噪音低：压缩状态不常见

**劣势**：
- ✗ 无法判断方向（只知道要爆发，不知道涨跌）
- ✗ 领先时间较长（不如成交量和订单流）

---

### 3.4 多周期共振（P0 - 强烈推荐）

**原理**：
- 1m/5m/15m同时出现"即将加速"信号
- → 多周期共振 → 加速概率极高

**指标定义**：
```python
# 多周期成交量共振
vol_resonance = (
    (vol_surge_1m > 1.5) and
    (vol_surge_5m > 1.5) and
    (vol_surge_15m > 1.5)
)

# 多周期订单流共振
tbr_resonance = (
    (tbr_accel_1m > 0.1) and
    (tbr_accel_5m > 0.05) and
    (tbr_accel_15m > 0.03)
)

# 如果共振 → 预测：即将加速
if vol_resonance and tbr_resonance:
    # 高置信度信号
```

**实际意义**：
- 短期（1m）、中期（5m）、长期（15m）都显示相同信号
- 说明不是噪音，是真实趋势
- 置信度极高

**优势**：
- ✓ 可靠性：极高（多周期确认）
- ✓ 假信号少：单周期噪音被过滤
- ✓ 实现简单：组合现有指标

**劣势**：
- ✗ 信号频率低：需要多周期同时满足
- ✗ 可能错过一些机会

---

### 3.5 接近关键支撑/阻力（P1）

**原理**：
- 价格接近关键位 → 触发止损/追单
- 止损/追单 → 加速

**指标定义**：
```python
# 距离1小时高低点
distance_to_1h_high = (price - high_1h) / price
distance_to_1h_low = (price - low_1h) / price

# 触发条件
if distance_to_1h_low < 0.002:  # 距离支撑位0.2%
    # 预测：可能跌破支撑，加速下跌
elif distance_to_1h_high < 0.002:  # 距离阻力位0.2%
    # 预测：可能突破阻力，加速上涨
```

**实际意义**：
- 2386可能是1小时支撑位
- 价格接近2386 → 多头止损挂单密集
- 跌破2386 → 触发止损 → 加速下跌

**案例分析（12:45大跌）**：
```
12:40  price=2386（接近支撑位）
     → 预警：可能跌破支撑
12:45  跌破2386 → 触发止损 → 加速下跌到2320
```

**优势**：
- ✓ 领先时间：2-10分钟
- ✓ 有方向性：可以判断涨跌
- ✓ 符合交易逻辑

**劣势**：
- ✗ 需要识别关键位（难度中等）
- ✗ 假突破较多

---

### 3.6 1分钟加速度（P0 - 强烈推荐）

**原理**：
- 5分钟加速度滞后10-15分钟
- 1分钟加速度滞后2-3分钟
- **更短的时间尺度 = 更快的识别**

**指标定义**：
```python
# 1分钟加速度
roc_accel_1m = roc_1m - roc_1m_lag1

# 触发条件
if roc_accel_1m < -0.001:  # 加速下跌
    # 预测：正在加速下跌（比5m早识别）
```

**实际意义**：
- 5分钟K线：12:45开始加速，12:50才识别（滞后5分钟）
- 1分钟K线：12:45开始加速，12:47就识别（滞后2分钟）
- **提前3分钟入场**

**优势**：
- ✓ 领先时间：比5m快3-5分钟
- ✓ 实现简单：当前数据就有
- ✓ 有方向性：可以判断涨跌

**劣势**：
- ✗ 噪音更多：1分钟波动大
- ✗ 需要结合5m确认

---

### 3.7 布林带挤压突破（P1）

**原理**：
- 布林带宽度收窄 = 波动率压缩
- 突破布林带 = 波动率扩张
- **挤压后的突破 = 加速启动**

**指标定义**：
```python
# 布林带宽度
bb_width = (bb_upper - bb_lower) / bb_mid

# 挤压状态
if bb_width < bb_width_ma20 * 0.5:
    # 极度挤压
    # 预测：即将突破
    
# 突破确认
if price > bb_upper:
    # 向上突破 → 加速上涨
elif price < bb_lower:
    # 向下突破 → 加速下跌
```

**实际意义**：
- 布林带宽度收窄 = 市场犹豫不决
- 突破上轨/下轨 = 方向确定
- 通常伴随加速

**优势**：
- ✓ 领先时间：5-10分钟
- ✓ 有方向性：可以判断涨跌
- ✓ 实现简单：当前数据就有

**劣势**：
- ✗ 假突破较多
- ✗ 需要结合成交量确认

---

### 3.8 大单流入（P1）

**原理**：
- 大单（单笔成交量 > 均值的5倍）
- 大单流入 = 巨鲸入场
- **巨鲸入场 = 即将加速**

**指标定义**：
```python
# 大单检测（需要逐笔成交数据）
large_order = trade_volume > trade_volume_mean * 5

# 大单流入统计
large_buy_count_1m = count(large_order and is_buy)
large_sell_count_1m = count(large_order and is_sell)

# 触发条件
if large_buy_count_1m > 3:  # 1分钟内3笔大单买入
    # 预测：即将加速上涨
```

**实际意义**：
- 散户：小单，影响小
- 巨鲸：大单，影响大
- 大单突然增加 = 巨鲸在行动

**优势**：
- ✓ 领先时间：1-3分钟
- ✓ 有方向性：可以判断涨跌
- ✓ 可靠性：高（巨鲸不会乱动）

**劣势**：
- ✗ 需要逐笔成交数据（当前没有）
- ✗ 实现难度：中等

---

### 3.9 订单簿失衡（P2）

**原理**：
- 买单量 >> 卖单量 → 买方力量强 → 即将上涨
- 卖单量 >> 买单量 → 卖方力量强 → 即将下跌
- **订单簿失衡先于价格变化**

**指标定义**：
```python
# 订单簿失衡（需要深度数据）
bid_volume = sum(bid_depth[:10])  # 前10档买单量
ask_volume = sum(ask_depth[:10])  # 前10档卖单量

imbalance = (bid_volume - ask_volume) / (bid_volume + ask_volume)

# 触发条件
if imbalance > 0.3:  # 买单量比卖单量多30%
    # 预测：即将上涨
elif imbalance < -0.3:  # 卖单量比买单量多30%
    # 预测：即将下跌
```

**实际意义**：
- 订单簿是"意图"（还没成交）
- 成交量是"结果"（已经成交）
- **意图先于结果**

**优势**：
- ✓ 领先时间：实时-1分钟（最快）
- ✓ 有方向性：可以判断涨跌
- ✓ 可靠性：高

**劣势**：
- ✗ 需要深度数据（当前没有）
- ✗ 实现难度：高
- ✗ 订单簿可能被操纵（假单）

---

### 3.10 资金费率极端值（P2）

**原理**：
- 资金费率 > 0.1% → 多头过度拥挤 → 可能回调
- 资金费率 < -0.1% → 空头过度拥挤 → 可能反弹
- **极端情绪 = 反转信号**

**指标定义**：
```python
# 资金费率（需要API）
funding_rate = get_funding_rate()

# 触发条件
if funding_rate > 0.001:  # 0.1%
    # 预测：多头过度，可能回调
elif funding_rate < -0.001:  # -0.1%
    # 预测：空头过度，可能反弹
```

**实际意义**：
- 资金费率 = 多空力量对比
- 极端值 = 一方过度拥挤
- 过度拥挤 = 容易踩踏

**优势**：
- ✓ 有方向性：可以判断涨跌
- ✓ 反映市场情绪

**劣势**：
- ✗ 领先时间：30-60分钟（较慢）
- ✗ 需要API（当前没有）
- ✗ 更适合中长期（不适合30分钟）

## 四、推荐实施方案

### 阶段1：立即实现（1周内）- P0指标

**目标**：添加最可靠、最容易实现的领先指标

**指标清单**：
1. ✅ **成交量爆发**（vol_surge_1m/5m/15m）
2. ✅ **主动买入占比加速度**（tbr_accel_1m/5m）
3. ✅ **ATR压缩比**（atr_compression_1m/5m）
4. ✅ **1分钟加速度**（roc_accel_1m）
5. ✅ **多周期共振**（组合以上指标）

**实现方式**：
```python
# 在 src/features/timeframe.py 中添加

# 1. 成交量爆发
vol_ma20 = vol.rolling(20).mean()
out[f"vol_surge{suffix}"] = vol / vol_ma20

# 2. 主动买入占比加速度
tbr = taker_buy / vol
tbr_lag5 = tbr.shift(5)
out[f"tbr_accel{suffix}"] = tbr - tbr_lag5

# 3. ATR压缩比
atr_ma20 = atr14.rolling(20).mean()
out[f"atr_compression{suffix}"] = atr14 / atr_ma20

# 4. 1分钟加速度（已有roc_accel_1m）
# 无需修改

# 5. 多周期共振（模型自动学习）
# 无需修改
```

**预期效果**：
- 提前1-5分钟识别加速
- 减少滞后性
- 提高胜率5-10%

### 阶段2：短期实现（2-4周）- P1指标

**指标清单**：

```python
# 1. 接近关键支撑/阻力
high_1h = df["high"].rolling(12).max()  # 1小时=12根5分钟

bb = bollinger_bands(close, period=20)
bb_width = bb["width"]
bb_width_ma20 = bb_width.rolling(20).mean()
out[f"bb_squeeze{suffix}"] = bb_width / bb_width_ma20
out[f"bb_position{suffix}"] = bb["position"]  # 0-1，突破时>1或<0
```

## 五、总结

### 5.1 最推荐的指标组合（P0）

**核心三件套**：
1. **成交量爆发**（vol_surge）→ 识别"有大资金"
2. **订单流失衡**（tbr_accel）→ 识别"买方/卖方强"
3. **1分钟加速度**（roc_accel_1m）→ 识别"正在加速"

**确认指标**：
4. **ATR压缩比**（atr_compression）→ 识别"蓄力状态"
5. **多周期共振**（resonance）→ 提高置信度

### 5.2 时间尺度建议

| 用途 | 推荐时间尺度 | 原因 |
|-----|------------|------|
| **快速识别加速** | 1分钟 | 滞后2-3分钟，噪音可控 |
| **主要交易信号** | 5分钟 | 当前使用，平衡速度和噪音 |
| **趋势确认** | 15分钟 | 过滤假信号，确认趋势 |
| **超短线（可选）** | 30秒 | 滞后1-2分钟，但噪音大 |

### 5.3 实施优先级

**第1周**：
- 添加P0指标（成交量、订单流、ATR压缩）
- 重新训练模型
- 回测验证

**第2-4周**：
- 添加P1指标（支撑/阻力、布林带）
- 下载30秒K线数据
- 对比v1/v2/v3效果

**第1-2个月**：
- 添加P2指标（订单簿、资金费率）
- 开发趋势跟踪模型
- 多模型集成
