# 信号输出格式说明

> 对应代码：`scripts/run_signal.py`  
> 最后更新：2026-04-22（v2 版本，EMA 趋势过滤器已移除）

---

## 一、完整输出结构

每根 5 分钟 K 线收盘后输出一个"Block"，由3部分组成：

```
[Bar 头部]          ← 1行
  [LONG 信号行]     ← 1行
  [SHORT 信号行]    ← 1行
[Session 摘要]      ← 4~6行
```

---

## 二、各字段说明

### Bar 头部（第1行）

```
2026-04-22 16:05 → 16:10 CST  price=2290.58
```

| 字段 | 格式 | 含义 |
|------|------|------|
| `2026-04-22 16:05 → 16:10 CST` | `YYYY-MM-DD HH:MM → HH:MM CST` | 刚关闭的K线开盘时间 → 收盘时间（北京时间） |
| `price=2290.58` | `float` | 该K线收盘价，作为进场参考价 |

> v1 版本有 `trend=↑(EMA20=... EMA60=...)` 字段，v2 起已移除。方向判断由模型内部特征（ret_net_4h_5m 等动量特征）完成，不再用简单 EMA 交叉过滤。

---

### 信号行（第2、3行）

```
  LONG  FIRE  prob=0.6105  tp=+0.920% → 2311.66  sl=-0.153% → 2287.07 ✓
  SHORT --    prob=0.3204  tp=+0.903% → 2269.88  sl=-0.155% → 2294.14  
```

| 字段 | 可能值 | 含义 |
|------|--------|------|
| 方向标签 | `LONG ` / `SHORT` | 信号方向 |
| 状态标签 | `FIRE` | 有效信号：概率 ≥ 阈值（默认 0.60） |
| | `--  ` | 未触发：概率低于阈值 |
| `prob=0.6105` | `float [0,1]` | 模型输出的校准后触发概率 |
| `tp=+0.920% → 2311.66` | `sign% → price` | 模型预测的止盈幅度（y_max）及对应目标价 |
| `sl=-0.153% → 2287.07` | `sign% → price` | 模型预测的止损幅度（y_min）及对应参考价 |
| 末尾符号 | `✓` | FIRE（有效信号） |
| | ` `（空格） | 未触发 |

**tp/sl 价格计算规则：**
- LONG：`tp_price = price × (1 + tp%)` ，`sl_price = price × (1 + sl%)`（sl% 为负）
- SHORT：`tp_price = price × (1 - tp%)`，`sl_price = price × (1 - sl%)`（sl% 为负，结果高于入场价）

---

### Session 摘要（每次输出末尾）

```
──────────────────────────────────────────────────────────
  运行开始 2026-04-22 07:55:00 UTC
  已检查 30 bars  |  LONG 触发 2 次  |  SHORT 触发 1 次
  最近 LONG : 16:10 (0.61)  22:15 (0.74)
  最近 SHORT: 09:35 (0.71)
──────────────────────────────────────────────────────────
```

| 字段 | 含义 |
|------|------|
| `运行开始` | 本次进程启动的 UTC 时间 |
| `已检查 N bars` | 本进程累计处理的 K 线数量 |
| `LONG 触发 N 次` | 累计 FIRE 的 LONG 信号次数 |
| `SHORT 触发 N 次` | 累计 FIRE 的 SHORT 信号次数 |
| `最近 LONG/SHORT` | 最近3次 FIRE 信号的收盘时间（HH:MM CST）和概率 |

## 四、状态枚举总表

| LONG 状态 | SHORT 状态 | 含义 |
|-----------|-----------|------|
| `--` | `--` | 双方概率均不足，普通 bar |
| `FIRE ✓` | `--` | 仅 LONG 有效触发 |
| `--` | `FIRE ✓` | 仅 SHORT 有效触发 |
| `FIRE ✓` | `FIRE ✓` | 双向均触发（高波动 bar，谨慎） |
| `NaN` | `NaN` | 模型 warmup，特征计算不足，跳过 |
