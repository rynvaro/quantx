# QuantX 合约训练设计文档

> 基于 Calm-Trigger 策略的 ETH/USDT 永续合约训练方案
> 日期：2026-04-14（更新：合并 model_design_final.md 内容，统一为唯一训练设计文档）
> 定位：仅训练设计，下单执行策略待模型验证后单独设计

---

## 一、核心直觉与目标

### 1.1 策略直觉

市场在积累期（低波动、平静背景）之后，一旦出现短时间的加速度突然放大，往往会带来一波定向动量。这波动量通常在 5-15 分钟内完成，之后可能衰减或反转。

**目标**：捕捉这一波动量行情，在动量启动后入场，在动量衰减前离场，每次获取一个可见的利润片段。

> 这就是 Calm-Trigger v1 的核心：弹簧压缩越深，触发后释放的能量越大，动量越持续。

### 1.2 训练要回答的三个问题

模型需要同时回答：

| 问题 | 对应输出头 | 训练类型 | 说明 |
|------|---------|---------|------|
| 这次会涨吗？ | `P(up)` | **分类** | 训练标签是 0/1（涨幅是否超过 `ENTRY_THRESHOLD` 门槛），模型输出该事件发生的概率（0~1） |
| 最多能涨多少？ | `max_gain` | **回归** | 训练标签是实际涨幅数值，模型输出预测的最大上涨幅度 |
| 最低会跌到哪？ | `min_drawdown` | **回归** | 训练标签是实际最大回撤数值（负数），模型输出预测的最低点偏移 |

> **关于分类标签的门槛（`ENTRY_THRESHOLD`）**：这是训练前人为定义的参数，不是模型计算出来的。含义是"涨幅达到这条线才算一次有价值的机会"。门槛的合理值需要根据实际数据验证，目标是让正样本比例落在 **20-30%**（详见 5.2 节）。

`max_gain` 决定是否值得入场（利润空间）；`min_drawdown` 提供自然止损参考位（跌破此位说明动量已失败）。

---

### 1.3 分类头的完整训练流程

以 `P(up)` 头为例，完整走一遍：

```
第一步（人工决定门槛）：
  "涨幅超过 ENTRY_THRESHOLD 才算一次有价值的机会"
  → 这个值由手续费成本和样本分布共同决定，训练前作为参数传入（见 5.2 节）

第二步（构造训练标签）：
  对历史上每一个时刻 T：
    if max_gain(T) >= ENTRY_THRESHOLD:  y_class = 1   ← 这是一次好机会
    else:                                y_class = 0   ← 不够好，跳过

第三步（模型训练）：
  XGBClassifier 学习：
  什么样的市场特征组合 X_T 更容易对应 y_class = 1？

第四步（模型输出）：
  新的时刻 T'，输入特征 X_T'
  → 模型输出 P(up) = 0.72
  → 含义：当前市场状态有 72% 的把握，未来 15min 涨幅会超过 ENTRY_THRESHOLD
  → 是概率，不是 True/False，方便后续判断这次机会质量有多好
```

---

### 1.4 最大涨幅回归头的完整训练流程（y_max）

```
第一步（标签直接来自历史数据，无需人工门槛）：
  "未来 15 根 1m K 线的最高价相对当前收盘价的涨幅是多少？"
  → 这个值是客观数值，不依赖任何主观参数

第二步（构造训练标签）：
  对历史上每一个时刻 T：
    future_close = close_1m[T+1 : T+16]
    y_max        = max(future_close) / close[T] - 1    ← 实际最大涨幅（正数，如 0.015 表示 +1.5%）

第三步（模型训练）：
  XGBRegressor 学习：
  什么样的市场特征组合 X_T 更容易对应更大的 y_max（利润空间更充裕）？

第四步（模型输出）：
  新的时刻 T'，输入特征 X_T'
  → 模型输出 y_max_pred = 0.018
  → 含义：预测本次动量最多能涨约 1.8%
  → 用于判断这次机会的盈利空间是否超过 ENTRY_THRESHOLD（利润预估）
```

> **与分类头的关系**：P(up) 回答"会不会涨"（0/1 概率），y_max 回答"如果涨，最多涨多少"。两者从不同角度刻画机会质量，互补而非重复。

---

### 1.5 最低点回归头的完整训练流程（y_min）

```
第一步（标签即为入场后的最大回撤）：
  "未来 15 根 1m K 线的最低价相对当前收盘价的偏移是多少？"
  → 描述入场后会经历的最大回撤深度

第二步（构造训练标签）：
  对历史上每一个时刻 T：
    future_close = close_1m[T+1 : T+16]
    y_min        = min(future_close) / close[T] - 1    ← 实际最大回撤（负数，如 -0.007 表示 -0.7%）

  注意：min_price 必须只用未来 K 线，不能包含当前 T 时刻数据，防止数据泄漏。

第三步（模型训练）：
  XGBRegressor 学习：
  什么样的市场特征组合 X_T 更容易对应 |y_min| 更小（回撤更浅、动量更干净）？

第四步（模型输出）：
  新的时刻 T'，输入特征 X_T'
  → 模型输出 y_min_pred = -0.006
  → 含义：预测入场后最深可能回落约 -0.6%
  → 用途：自然止损参考位——实际价格跌破此幅度，说明动量方向已失败
```

> **为什么需要 y_min**：固定百分比止损（如一律 -0.5%）忽略了每次动量的"质量"差异。y_min 基于当前市场状态给出预测性回撤深度，弹簧压缩越深、动量越强，预期回撤越浅。

---

### 1.6 三个头如何配合

三个头输出不同维度的信息，在推理时按序形成"三重过滤 + 盈亏评估"框架：

```
            ┌─────────────────────────────────────────────────────┐
            │  输入示例：P(up)=0.72，y_max=+1.8%，y_min=-0.6%    │
            └─────────────────────────────────────────────────────┘
                                     │
        ┌────────────────────────────▼────────────────────────────┐
        │  第一道过滤：P(up) ≥ 概率阈值？                         │
        │  0.72 ≥ 0.65  → 通过 ✓                                 │
        │  （概率不足直接跳过，不再看后续两个头）                  │
        └────────────────────────────┬────────────────────────────┘
                                     │
        ┌────────────────────────────▼────────────────────────────┐
        │  第二道过滤：y_max ≥ ENTRY_THRESHOLD？                  │
        │  1.8% ≥ 1.0%  → 通过 ✓                                 │
        │  （即使概率高，预测利润空间不足也不入场）                 │
        └────────────────────────────┬────────────────────────────┘
                                     │
        ┌────────────────────────────▼────────────────────────────┐
        │  盈亏比参考：y_max / |y_min|                            │
        │  1.8% / 0.6% = 3.0  → 盈亏比 3:1                       │
        │  y_min = -0.6%  → 自然止损参考位                        │
        └────────────────────────────┬────────────────────────────┘
                                     │
                          → 触发信号，进入下单决策
```

| 输出头 | 回答的问题 | 在配合中的角色 |
|--------|-----------|---------------|
| `P(up)` | 动量会不会启动？ | **粗过滤**：概率不足直接否决，排除大多数噪声时刻 |
| `y_max` | 如果启动，最多涨多少？ | **盈利验证**：确认利润空间超过成本门槛，防止"信号准但赚不到钱" |
| `y_min` | 入场后最深会跌多少？ | **风险定量**：提供自然止损参考位，使每次入场都有数据支撑的止损依据 |

> **注意**：盈亏比和止损价位的实际使用规则属于执行层逻辑，不在训练阶段固化。训练阶段目标是让三个头的预测本身尽可能准确；如何将三个数值转化为具体交易动作，留待下单策略文档设计。

## 二、品种与数据

### 2.1 训练品种

- **品种**：ETH/USDT 永续合约（U本位）
- **选择原因**：
  - ETH 比 BTC 波动率高约 20-40%，动量行情更频繁，更符合短线策略
  - U本位合约，盈亏以 USDT 计算，直观
  - Binance Data Portal 有完整的 ETH/USDT 历史数据

> **注意**：ETH 的特征阈值（ATR、ROC幅度、成交量基准）与 BTC 不同，不能直接套用 BTC 训练的模型或参数。所有阈值需基于 ETH 历史数据重新标定。

### 2.2 历史数据范围

- **来源**：Binance Data Portal（data.binance.vision）
- **时间范围**：2021-01 至 2025-12（5 年）
  - 涵盖 2021 牛市 / 2022 熊市 / 2023 震荡 / 2024-2025 再牛熊周期
  - 5 年数据确保各市场状态都有足够样本
- **需要下载的粒度**：1m / 5m / 15m / 1h / 4h，独立下载
- **资金费率**：单独下载 fundingRate（8小时频率），作为市场情绪参考特征

### 2.3 K线列名（无标题，固定顺序）

```
列序  字段名                    说明
0     open_time                  开盘时间（Unix 毫秒）
1     open / 2 high / 3 low / 4 close
5     volume                     成交量（ETH）
6     close_time
7     quote_volume               成交额（USDT）
8     count                      成交笔数
9     taker_buy_volume           主动买入量（ETH）
10    taker_buy_quote_volume     主动买入额（USDT）
11    ignore
```

### 2.4 数据过滤

```python
# 1. 过滤周末（本阶段只训练工作日模型）
df = df[df["open_time"].dt.dayofweek <= 4]

# 2. 过滤极端行情（避免黑天鹅污染训练集）
atr_zscore = (ATR_1m - ATR_1m.rolling(200).mean()) / ATR_1m.rolling(200).std()
df = df[atr_zscore < 4.0]
```

**第一条过滤——周末过滤**

`dayofweek` 返回 0（周一）到 6（周日），`<= 4` 即保留周一到周五。

过滤原因：加密货币合约 7×24 小时交易，但周末成交量通常比工作日低 30-50%，流动性结构不同。弹簧压缩策略依赖成交量爆发对比信号——周末的"成交量萎缩"本身不是弹簧积累，而是自然低谷；若混入训练，会让模型误学低流动性时段的模式。本阶段先只训练工作日模型，周末策略视后续需要单独建模。

**第二条过滤——极端行情过滤（ATR Z-score）**

`ATR_1m.rolling(200).mean()` 是过去 200 根 1m K 线的 ATR 均值，`.std()` 是同窗口的标准差。Z-score 公式：

$$z = \frac{ATR_t - \mu_{200}}{\sigma_{200}}$$

含义：当前 ATR 比过去 200 分钟的平均水平偏高了几个标准差。`atr_zscore < 4.0` 即保留波动率在"正常范围 4 倍标准差以内"的 K 线。

过滤原因：z > 4.0 对应交易所宕机、重大黑天鹅（如 2022-05 LUNA 崩盘、2022-11 FTX 暴雷）这类异常行情。这些时刻的特征-标签关系与正常动量完全不同（成交量失真、滑点极大、流动性蒸发），保留在训练集会污染模型对正常弹簧信号的学习，且实盘中这类时刻本就不应该入场。

> **过滤后样本量**：45-50 万条（工作日全量）→ 过滤极端行情后约 **38-42 万条**，损失约 10% 样本，均为异常时段，损失可接受。

## 三、滑窗样本构造

### 3.1 滑窗步长

- **步长：5 分钟**
- 原因：5min 步长下相邻样本的标签重叠适中（共享 10/15 分钟），同时保留足够样本量
- 5 年工作日数据：约 **45-50 万条样本**（过滤后约 38-42 万条）

### 3.2 样本结构

```
对历史时间轴上每个步长为 5min 的时刻 T（1m K线收盘时刻）：

输入 X_T：T 时刻之前的多时间框架特征向量（见第四章）

标签 y_T：
  future_close = close_1m[T+1 : T+16]       # 未来 15 根 1m close

  max_gain      = max(future_close) / close[T] - 1          # 最大上涨幅度（正数）
  min_drawdown  = min(future_close) / close[T] - 1          # 最大回撤幅度（负数或小正数）

  y_class = 1  if max_gain >= ENTRY_THRESHOLD  else  0      # ENTRY_THRESHOLD 见第六章
  y_max   = max_gain                                         # 回归：最大涨幅
  y_min   = min_drawdown                                     # 回归：最低点偏移

约束：特征只使用 T 及 T 之前的数据，标签只使用 T 之后的数据。
```

### 3.3 三个标签的直觉解释

```
价格走势示例（T 时刻入场后 15 分钟）：

close[T] = 2000 USDT

                     ↑ max_gain = +1.5%（最高到 2030）
                    ╱╲
                   ╱  ╲
  ──── T ─────────╱    ╲──────────────────── 15min 后
                            ↓ min_drawdown = -0.4%（最低跌到 1992）

→ 这次动量：最多能赚 1.5%，过程中最深回撤 -0.4%
→ 如果实际跌破 -0.4% 以下，说明动量完全失败，应该止损离场
```

## 四、特征工程

### 4.1 多时间框架结构

| 粒度 | 取最后N根 | 覆盖时长 | 特征类型 |
|------|---------|--------|---------|
| 1m | 30 根 | 30 分钟 | 完整多阶特征 |
| 5m | 24 根 | 2 小时 | 完整多阶特征 |
| 15m | 16 根 | 4 小时 | 完整多阶特征 |
| 1h | 24 根 | 1 天 | 趋势性指标 |
| 4h | 30 根 | 5 天 | 趋势性指标 |

每个时间框架取当前时刻 T 对应的**最后一根 K 线的指标值**，拼接为一维特征向量。

---

### 4.2 弹簧压缩层（Calm Layer）

> **弹簧模型的第一层**：背景积累了多少能量

| 特征名 | 计算方式 | 意义 |
|-------|---------|------|
| `vcdi` | `(1 - percentile_rank(ATR_14, 200)) × log(1 + compress_bars)` | 波动率压缩深度 × 持续时长，越大弹簧越紧 |
| `earp` | `percentile_rank(bb_width, 200) × sign(ROC(bb_width, 5))` | 布林带由收转扩的转折相位，由负转正=能量开始释放 |
| `bb_width_pct` | `percentile_rank(bb_width_1m, 200)` | 当前布林带宽度的历史分位，越低越压缩 |
| `compress_bars` | 连续满足 `ATR_14 < mean(ATR_14, 50)` 的 K 线数 | 压缩持续时长 |

---

### 4.3 动量触发层（Trigger Layer）

> **弹簧模型的第二层**：触发加速是否出现

**三窗口加速度族（向内细化，核心设计）**：

| 特征名 | 计算方式 | 意义 |
|-------|---------|------|
| `roc_5` | `(close[-1] - close[-6]) / close[-6]` | 5根K线动量（一阶） |
| `roc_3` | `(close[-1] - close[-4]) / close[-4]` | 3根K线动量 |
| `roc_1` | `(close[-1] - close[-2]) / close[-2]` | 即时动量 |
| `roc_accel_5` | `roc_5[-1] - roc_5[-2]` | 5m 窗口加速度（二阶）|
| `roc_accel_3` | `roc_3[-1] - roc_3[-2]` | 3m 窗口加速度 |
| `roc_accel_1` | `roc_1[-1] - roc_1[-2]` | 即时加速度 |
| `volume_accel` | `volume[-1] / mean(volume[-5:]) - 1` | 成交量爆发比率 |
| `trigger_score` | `roc_accel_5 × max(volume_accel, 0)` | 量价结合的触发强度（Calm-Trigger 核心）|

> **三档加速度一致性**：如果 `sign(roc_accel_5) == sign(roc_accel_3) == sign(roc_accel_1)`，说明加速正在向更短周期扩散，是更强的触发信号。这个"一致性"也作为一个布尔特征加入：
>
> ```
> accel_consensus = int(sign(roc_accel_5) == sign(roc_accel_3) == sign(roc_accel_1) == 1)
> ```

---

### 4.4 量价强度层（Momentum Confirmation Layer）

> 验证触发是否有实质买盘支撑

| 特征名 | 计算方式 | 意义 |
|-------|---------|------|
| `taker_buy_ratio` | `taker_buy_vol / volume` | 主动买入占比，>0.6 说明买方主导 |
| `bsipi` | `mean(taker_buy_ratio - 0.5, 10) × sqrt(consec_bull + 1)` | 持续性买压强度 |
| `cbfi_ema` | `EMA((stance - 0.5) × 2 × vol_ratio, 5)` | 量能加持的收盘位置强度 |
| `mvdi` | `(roc_5 / std(roc_5, 50)) / (ATR_14 / mean(ATR_14, 50))` | 动量波动率解耦（>2=静默大单推动）|
| `pei` | `EMA(impact, 5) / EMA(impact, 20) - 1` | 价格弹性恢复（>0=阻力消耗完毕）|
| `cpai` | `mean([sign(roc_1m), sign(roc_5m), sign(roc_15m)]) × mean([abs(roc_1m), abs(roc_5m), abs(roc_15m)])` | 跨周期动量共振（+1 且幅度大=三框架全多头对齐）|

> **mvdi / pei / cpai 的弹簧模型逻辑分析**（未验证，但逻辑合理）：
>
> - `mvdi`（动量波动率解耦）：本质是"标准化动量 ÷ 标准化波动率"。弹簧压缩期 ATR 低，若此时出现定向价格推动，mvdi 异常高——正是"低噪声背景下的定向大单"的统计表达，与弹簧触发逻辑高度吻合。
> - `pei`（价格弹性恢复）：每单位成交量推动的价格变化。pei 由负转正意味着卖方阻力耗尽，买方开始能高效推价——这是弹簧蓄力阶段"阻力墙崩塌"的量化信号，与 Wyckoff 弹簧理论一致。
> - `cpai`（跨周期动量共振）：要求 1m/5m/15m 三框架同时方向一致且幅度有意义。弹簧释放时能量向上传导在所有时间尺度同步可见——框架一致性越高，说明释放越有力，不是局部噪声。
>
> 三者均有弹簧物理支撑，暂时保留，SHAP 分析后决定取舍。

### 4.5 趋势背景层（Trend Context Layer）

> **P0 级别**：短线胜率在不同牛熊状态下差异高达 20-30%

| 特征名 | 计算方式 | 时间框架 |
|-------|---------|---------|
| `trend_score` | `mean([sign(EMA9_4h-EMA21_4h), sign(EMA21_4h-EMA55_4h), sign(close_1d-EMA200_1d)])` | 4h + 1d |
| `ema_slope_4h` | `(EMA55_4h[-1] - EMA55_4h[-10]) / EMA55_4h[-10]` | 4h |
| `deviation_1d` | `close_1d / EMA200_1d - 1` | 1d |
| `rsi_regime_4h` | `RSI(close_4h, 14) / 100` | 4h |
| `macd_zone_1h` | `sign(MACD_hist_1h[-1])` | 1h |
| `adx_4h` | `ADX(4h, 14)` | 4h |
| `funding_rate` | 最近一次资金费率值 | 8h |
| `hour_of_day` | `open_time.hour` (0-23) | — |
| `day_of_week` | `open_time.dayofweek` (0-4) | — |

### 4.6 基础技术指标层 + 统计特征层

> 传统指标作为背景上下文；统计特征量化序列可预测性

**基础技术指标（1m / 5m / 15m 各计算一套）**：

| 特征名 | 计算方式 | 时间框架 |
|-------|---------|----------|
| `ema_fast` | EMA(close, 9) | 1m / 5m / 15m |
| `ema_slow` | EMA(close, 21) | 1m / 5m / 15m |
| `ema_cross` | `ema_fast / ema_slow - 1` | 1m / 5m / 15m |

**统计特征（1m / 15m）**：

| 特征名 | 计算方式 | 意义 |
|-------|---------|------|
| `hurst` | Hurst 指数，窗口 100 | > 0.5 趋势性，< 0.5 均值回归 |

| `autocorr_lag5` | close 序列滞后 5 期自相关系数 | 短期动量持续性 |

> **各指标使用建议**：
> - `atr_14` / `bb_width` / `rsi_14` / `macd_hist` / `bb_position`：与弹簧模型间接相关（ATR 和 bb_width 直接是压缩检测基础），保留等待 SHAP 验证
> - `hurst` / `sample_entropy` / `autocorr_lag5`：是弹簧模型在统计物理层的映射（压缩期熵低/Hurst<0.5，释放后 Hurst>0.5），逻辑合理，保留等待验证
> - `ema_cross`（1m/5m）：对短线触发反应滞后，与 `accel_consensus` 语义重叠，**存疑，SHAP 后优先候选删除**
> - `vwap_dev`：均值回归逻辑（偏离越多越可能回归），与弹簧模型"顺势突破"哲学相反，**存疑，SHAP 后优先候选删除**

### 4.7 新增弹簧物理特征（实验组）

> 基于力学原理推导的补充特征，填补当前设计对"弹簧质量"和"释放阶段"刻画不足的空白

| 特征名 | 计算方式 | 力学依据 |
|-------|---------|---------|
| `compress_quality` | `std(returns_in_compression_window)` | 压缩越有序（std 越低），释放方向性越强；杂乱震荡的压缩释放后方向不确定 |
| `vol_dry_ratio` | `mean_vol_compress / mean_vol_pre_compress` | 蓄力期成交量萎缩（越低越安静），触发时爆发对比越强，信号越可信 |
| `price_in_range` | `(close - min(close, compress_bars)) / (max(close, compress_bars) - min(close, compress_bars) + ε)` | 向上释放时价格应靠近压缩区间顶部（接近 1.0），方向性更强 |
| `release_phase` | `sign(trigger_score[-1] - trigger_score[-3])` | +1=加速仍在持续（早期最优入场），-1=加速已见顶（晚期，谨慎）|

> 全部列入实验组，与现有模型对比后决定是否纳入正式特征集。

### 4.8 综合弹簧指数（CTI）

> Calm-Trigger 策略的最终显式编码，作为独立特征输入模型

    trend_score >= 0          and    # 不在明确空头背景下做多

## 五、标签定义

### 5.1 三个输出头的标签

```python
future_close = close_1m.iloc[T+1 : T+16]    # 未来 15 根 1m 收盘价

# 头1：分类标签
max_gain     = max(future_close) / close[T] - 1
y_class      = 1 if max_gain >= ENTRY_THRESHOLD else 0

# 头2：最大涨幅回归
y_max        = max_gain

# 头3：最低点回归（负数，代表最大回撤）
min_price    = min(future_close)
y_min        = min_price / close[T] - 1      # 通常为负值，如 -0.004 表示 -0.4%
```

### 5.2 入场门槛（ENTRY_THRESHOLD）的设定

ETH 合约的成本结构（以后续执行层为参考，训练时先用估算值）：

```
Taker 手续费（单边）≈ 0.05%
双边手续费          ≈ 0.10%
资金费率（持仓15min）≈ 可忽略（8h费率 / 32 ≈ 每15min约0.002%）
滑点估计            ≈ 0.05%
────────────────────────────────
总成本（单次交易）   ≈ 0.15%
```

**ENTRY_THRESHOLD 初始建议值**：`1.0%`

**为什么不是 0.5%（手续费倒推的值）**：

ETH 日波动率约 3-4%，换算到 15 分钟的随机游走期望波动约为：

```
4% / √96 ≈ 0.4%
```

即使没有任何信号，ETH 在 15 分钟内自然波动就能轻易超过 0.5%，正样本比例可能高达 40-50%。这样的分类问题太容易，模型倾向于"大多数时候都涨"，学不到 Calm-Trigger 的真正判别能力。

**合理门槛的判断标准**：正样本比例落在 **20-30%**，模型才被迫学习"什么特殊状态下才会发生有意义的上涨"。

**ENTRY_THRESHOLD 作为参数在训练前传入，不硬编码**，实际值以数据验证为准：

```python
ENTRY_THRESHOLD = 0.010  # 初始值 1.0%，训练前可调整

# 训练前先扫描正样本比例，选落在 20-30% 区间的值
for threshold in [0.005, 0.008, 0.010, 0.012, 0.015]:
    rate = (max_gain >= threshold).mean()
    print(f"{threshold*100:.1f}%  →  正样本占比 {rate:.1%}")
```

> 成本保障：1.0% - 0.15%（手续费+滑点）= **净利润空间 0.85%**，安全边际充足。

### 5.3 `y_min` 的含义与用途

```
示例：
  close[T] = 2000 USDT
  y_max    = +0.012  → 最高到 2024   （+1.2%）
  y_min    = -0.005  → 最低到 1990   （-0.5%）

意义：
  模型预测的 y_min = -0.5%
  → 在执行层设计时，-0.5% 是这笔交易的"自然止损位"
  → 如果价格跌破 1990，说明动量已经失败，应该离场
  → 如果价格没有跌破，而涨到了 2024，这笔交易成功
```

`y_min` 不是用来预测"入场后一定会跌这么多"，而是预测"这个市场状态下的正常噪声下界"——跌破这个界，说明弹簧没有正常释放，动量失败。

## 六、模型设计

### 6.1 独立三头模型（首选实施方案）

三个独立模型，共享相同的特征输入：

```
特征向量 X_T（50-65维）
      │
      ├──→ XGBClassifier  → P(up)      （分类：动量会不会启动）
      ├──→ XGBRegressor   → y_max      （回归：最大能涨多少）
      └──→ XGBRegressor   → y_min      （回归：最低会跌到哪）
```

独立训练的优点：各头单独调参，互不干扰；可以单独评估每个头的质量。

### 6.2 关键训练设置

**分类头（y_class）**：

```
objective:        binary:logistic
eval_metric:      logloss + aucpr（精确率-召回曲线下面积，适合不均衡样本）
scale_pos_weight: 负样本数 / 正样本数（处理正负样本不均衡）
```

**最大涨幅回归头（y_max）**：

```
objective:   reg:squarederror 或 reg:pseudohubererror（对异常值鲁棒）
eval_metric: rmse
```

**最低点回归头（y_min）**：

```
objective:   reg:squarederror
eval_metric: rmse
注意：y_min 通常是负值（回撤），需要确保模型没有用到未来数据计算 min_price
```

**通用超参数范围**：

```
n_estimators:     500 - 1500
max_depth:        4 - 6
learning_rate:    0.01 - 0.05
subsample:        0.7 - 0.85
colsample_bytree: 0.6 - 0.8
min_child_weight: 10 - 30
reg_lambda:       2 - 10
```

### 6.3 概率校准（分类头必做）

```python
# 在验证集上做 Platt Scaling
from sklearn.calibration import CalibratedClassifierCV
calibrated_clf = CalibratedClassifierCV(clf, method="sigmoid", cv="prefit")
calibrated_clf.fit(X_val, y_val_class)

# 校准后验证分桶实际胜率（目标）：
# 模型输出区间     实际胜率目标
# [0.60, 0.65)    ≥ 52%
# [0.65, 0.70)    ≥ 57%
# [0.70, 0.80)    ≥ 62%
# [0.80, 1.00)    ≥ 68%
# 根据分桶结果动态调整入场概率阈值，不固定用 0.65
```

## 七、训练验证方案

### 7.1 Walk-forward 验证结构

```
时间轴（5年，工作日）：
2021-01 ──────────────────────────────────────── 2025-12

折次  │  训练集              │  验证集
───────┼────────────────────────────────────
第1折  │  2021-01 ~ 2022-12  │  2023-01 ~ 2023-06
第2折  │  2021-01 ~ 2023-06  │  2023-07 ~ 2023-12
第3折  │  2021-01 ~ 2023-12  │  2024-01 ~ 2024-06
第4折  │  2021-01 ~ 2024-06  │  2024-07 ~ 2024-12
第5折  │  2021-01 ~ 2024-12  │  2025-01 ~ 2025-06
第6折  │  2021-01 ~ 2025-06  │  2025-07 ~ 2025-12

规则：
  - 训练集和验证集之间保留 5 天间隔（防止标签泄漏）
  - 每折分别记录 Precision / IC / 夏普比率，观察跨时间稳定性
  - 分别检查牛市折（2021下半年、2024）和熊市折（2022、2023上半年）的表现差异
```

### 7.2 评估指标

| 指标 | 针对哪个头 | 目标值 | 说明 |
|------|---------|-------|------|
| Precision@P>0.65 | 分类头 | > 58% | 触发信号时的实际胜率 |
| IC（Spearman） | y_max 回归头 | > 0.05 | 预测涨幅与实际涨幅相关性 |
| IC（Spearman） | y_min 回归头 | > 0.04 | 预测最低点与实际最低点相关性 |
| RMSE 相对误差 | y_max | < 0.5% | 预测涨幅误差 |
| 牛熊一致性 | 所有头 | 各折 Precision 差异 < 10% | 防止只在牛市好用 |
| SHAP — CTI 排名 | 分类头 | 进 Top 10 | 验证弹簧策略的有效性 |
| SHAP — accel_consensus 排名 | 分类头 | 进 Top 15 | 验证三档加速一致性的效果 |

### 7.3 SHAP 分析重点

训练完成后，用 SHAP 回答三个问题：

1. **CTI 的贡献是否显著**？如果 CTI 在 feature importance 中排名过低（< 30），说明弹簧模型的显式编码没有带来额外信息，需要重新审视 CTI 的构造方式。
2. **三个时间框架的贡献是否都有意义**？如果 4h 数据的贡献接近零，可以简化到只用 1m / 5m / 15m。
3. **哪些特征无效**？Shapley 值接近零的特征从下一次训练中剔除，减少维度。

## 十一、模型推理流程（训练完成后）

模型训练完成后，推理的完整流程如下：

```
第一步：实时获取 K 线数据
  通过 Binance API 拉取当前时刻 T 的最新 K 线
  需要 5 个时间框架：1m / 5m / 15m / 1h / 4h
  同时拉取最新的资金费率

第二步：计算特征指标
  用与训练时完全相同的方式，计算所有特征（弹簧压缩层、触发层、量价层……）
  用训练时保存的 scaler 做归一化 ← 必须用训练时的，不能重新 fit
  输出一个 flatten 特征向量 X_T

第三步：输入模型，得到三个预测值
  P(up)   = clf_model.predict_proba(X_T)   → 动量启动的概率（0~1）
  y_max   = reg_max_model.predict(X_T)     → 预测最大涨幅
  y_min   = reg_min_model.predict(X_T)     → 预测最低点偏移（负数）

第四步：判断是否是好机会（下单策略文档中定义，此处仅示意）
  if P(up) > 阈值 and y_max > ENTRY_THRESHOLD:
      → 触发信号，进入下单决策流程

注意：
  - scaler 文件必须和模型文件配套保存，推理时一起加载
  - 每次增量重训后，scaler 和模型同步更新
```
