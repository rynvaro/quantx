## 一、策略直觉描述

假设训练时刻为 A：

- 取 **A-1h** 内的价格平稳度或波动量，作为"背景状态"特征
- 取 **A-5min** 内的成交量或价格加速度变化，作为"触发信号"特征
- 以 **A+15min** 的结果（最大涨幅）作为训练标签

**核心假设**：在平静背景下出现的定向加速，是真实趋势启动的前兆，而不是噪声。

---

## 二、背后的市场哲学

### 弹簧模型

市场像弹簧：
- **压缩期**（A-1h 平稳）：买卖双方在窄区间积累筹码，价格波动率低
- **触发点**（A-5min 加速）：某一方开始占据优势，出现定向的量价异动
- **释放期**（A+15min）：被压缩的能量定向释放，产生可交易的趋势性移动

### 条件化信号（Regime-Conditional Signal）

同一个短期信号，在不同背景下的预测价值完全不同：
- **背景平稳 + 短期加速** = 有效买入信号
- **背景已经混乱 + 短期加速** = 噪声叠加噪声，无意义

这解释了为什么单独看"成交量加速"的预测力很弱——它被所有背景状态下的样本平均掉了。引入背景状态作为条件，模型才能区分哪些加速是真实的。

---

## 三、初步特征定义

```python
# 背景平稳度（A 时刻之前 1 小时的波动率低位程度）
calm_score = 1 / percentile_rank(ATR_1m_recent, window=60)
# ATR 越低于历史分布，calm_score 越高

# 触发强度（A 时刻之前 5 分钟的定向加速）
trigger_score = abs(roc_accel_1m) × volume_accel_1m

# 组合信号
Calm_Trigger_Index (CTI) = calm_score × trigger_score × sign(roc_5m)
# CTI > 0 且大 → 平静背景下出现了向上的定向加速 → 潜在买入信号
```

## 四、训练结构

```
输入：
  feature_background  = calm_score（A-1h 的平稳度）
  feature_trigger     = trigger_score（A-5min 的加速度）
  combined            = CTI

标签：
  y_class = 1  如果 max(close[A+1 : A+15]) / close[A] - 1 >= 0.8%
  y_class = 0  否则
  y_reg   = max(close[A+1 : A+15]) / close[A] - 1
```

## 五、当前局限性

1. 特征只有两个维度，信息量有限
2. "平静度"和"加速度"的阈值目前未经回测量化
3. 没有方向过滤（大趋势方向未纳入）
4. CTI 只作为独立信号，未与其他多阶特征体系结合
5. 滑窗步长未确定
