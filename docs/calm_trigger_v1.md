# Calm-Trigger 策略 v1

> 在 v0 思路基础上的系统化设计
> 日期：2026-04-09

---

## 一、策略定位

Calm-Trigger 不是一个独立系统，而是 QuantX Model-15m 的**核心信号逻辑层**。

它回答的问题是：**什么样的时刻值得入场？**

答案是：**大背景平静 + 短期定向加速启动的那个时刻。**

---

## 二、核心概念：三层时间结构

```
[宏观趋势层]          [背景状态层]           [触发层]           [目标]
  4h / 1d                A-1h                 A-5min            A+15min
  
  趋势方向滤镜    ×    波动率压缩深度    ×    定向加速强度    →   涨幅预测
  （允许/拒绝）         （背景可信度）         （信号强度）
```

三层缺一不可：
- **只有宏观方向**：不知道什么时候动
- **只有背景平静**：不知道是否真的要启动
- **只有短期加速**：噪声太多，大量是假突破
- **三层同时满足**：高置信度的买入时机

---

## 三、量化定义

### 3.1 背景平稳度（Calm Score）

衡量 A 时刻之前 1 小时内，市场有多"安静"。

```python
# 方法一：ATR 分位压缩
atr_recent   = ATR(close_1m, 14)  # 当前 ATR
atr_pct_rank = percentile_rank(atr_recent, window=200)  # 在近 200 根K线中的分位
calm_score   = 1 - atr_pct_rank   # 越低越平静，值域 [0, 1]

# 方法二：波动率压缩持续时长加权
compress_bars = 连续满足 atr < mean_atr_50 的 K 线数
calm_depth    = calm_score × log(1 + compress_bars)
# 压得越久越深，calm_depth 越高
```

**直觉**：calm_depth = 0.7 意味着"已经在近 200 根K线中处于低波动率的 70% 分位，且持续了一段时间"——弹簧压缩程度高。

---

### 3.2 触发强度（Trigger Score）

衡量 A 时刻之前 5 分钟内，市场是否出现了定向的、有成交量支撑的加速。

```python
# 价格加速度（动量的导数）
roc_5       = ROC(close_1m, 5)            # 5根K线的ROC
roc_accel   = roc_5[-1] - roc_5[-2]       # 加速度

# 成交量加速度
vol_ratio   = volume[-1] / mean(volume[-5:])  # 最后一根K线成交量相对近5根的比值

# 方向判断
direction   = sign(roc_5[-1])             # 当前动量方向

# 触发强度（方向性加速 × 成交量放大）
trigger_score = direction × abs(roc_accel) × vol_ratio
# > 0 且大 → 向上加速且量增   （买入触发）
# < 0 且绝对值大 → 向下加速  （不入场）
```

---

### 3.3 宏观趋势滤镜（Trend Filter）

只在大趋势方向支持时，才允许 Calm-Trigger 信号触发。

```python
trend_ok = (
    EMA(close_4h, 9) > EMA(close_4h, 21)   and  # 4h EMA 多头排列
    RSI(close_4h, 14) > 50                  and  # 4h 处于多头区制
    MACD(close_1h).hist > 0                      # 1h MACD 区间看涨
)
```

---

### 3.4 Calm-Trigger 综合指数（CTI）

```python
CTI = calm_depth × max(trigger_score, 0) × int(trend_ok)
# 只有趋势滤镜通过时 CTI 才非零
# CTI > 阈值（通过回测确定）→ 触发买入信号候选
```

## 四、训练样本构造

### 4.1 滑窗步长：推荐 5 分钟

| 步长 | 年样本量 | 标签重叠度 | 适用性 |
|------|--------|-----------|-------|
| 1min | ~50 万 | 极高，相邻样本标签共享 14/15 分钟 | 伪样本多，模型学到错误规律 |
| **5min** | **~10 万** | **中，共享 10/15 分钟** | **推荐：平衡点** |
| 15min | ~3.5 万 | 零，标签完全独立 | 样本量偏少 |

> **5 分钟步长的物理意义**：Calm-Trigger 结构本身是一个持续数分钟的状态切换过程，5 分钟采样恰好能捕捉状态边界的前后变化，同时大幅减少相邻样本之间的标签信息重叠。

### 4.2 样本结构

```
对历史数据上每个满足步长的时刻 A：

输入 X_A：
  ├── 背景层：calm_depth（A 时刻的 1h 平稳度）
  ├── 触发层：trigger_score（A 时刻的 5min 加速度）
  ├── 趋势层：4h / 1h 趋势指标
  └── 完整多阶特征（来自 quantx_design.md 第 4.2 节的特征体系）

标签 y_A：
  y_class = 1  如果 max(close[A+1 : A+15]) / close[A] - 1 >= 0.8%
  y_class = 0  否则
  y_reg   = max(close[A+1 : A+15]) / close[A] - 1
```

## 五、策略演进路线

### v0（原始直觉）
- 两个特征：1h 平静度 + 5min 加速度
- 逻辑清晰但信息量不足

### v1（本文档）
- 三层结构：宏观趋势滤镜 × 背景平稳度 × 触发强度
- 引入时长加权的 calm_depth
- 引入量价结合的 trigger_score
- 明确 5min 滑窗步长
- CTI 作为特征之一（而非唯一决策因子）输入 Model-15m

### v2（待探索方向）

1. **动态平静时长特征**：不只看"压了多久"，还看"压缩曲线的形状"（线性收窄 vs 已经反弹过多次）
2. **触发后确认机制**：CTI 触发后，不立即入场，等待下一根 1m K线确认方向（减少假破）
3. **多品种共振**：BTC 的 Calm-Trigger 与 ETH 的同步触发，互相印证（加密市场高相关性可利用）
4. **反向模式研究**：平静背景下的向下触发，是否可以预测 15min 后的做空机会（方向延伸）
5. **分时段有效性验证**：Calm-Trigger 在亚洲盘、欧美盘的有效性是否不同（流动性差异）

## 六、与主文档（quantx_design.md）的关系

CTI（Calm-Trigger Index）在整个 QuantX 特征体系中的位置：

```
特征体系
├── 零阶指标（原始数据）
├── 一阶指标（技术指标）
├── 二阶指标（加速度族）          ← trigger_score 的基础来自这里
├── 高阶指标（自设计实验性）
│   ├── VCDI（波动率压缩深度）    ← calm_depth 与此高度相关
│   ├── MVDI、PEI、CBFI 等
│   └── CTI（本文档的核心输出）  ← 跨时间尺度的显式交叉特征
└── 大周期趋势滤镜（1h/4h/1d）   ← trend_ok 来自这里
```

CTI 的核心价值在于它是一个**跨时间尺度的显式交叉特征（Cross-Timeframe Interaction Feature）**：它把背景状态和短期触发的组合效应显式编码，而不是依赖模型自己从分离特征中学到这个交互关系。

---

## 七、总结

Calm-Trigger 策略的本质是对这句话的量化：

> **安静了足够久之后，第一次定向加速，是最值得信任的入场信号。**

这不是一个完整的交易系统，而是 QuantX Model-15m 的核心信号直觉的形式化表达。它解释了为什么要同时看多个时间框架，以及不同时间框架的特征应该如何"协同"而非简单拼接。
