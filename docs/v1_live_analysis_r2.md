## 四、核心问题分析

### 问题 1：LONG 信号仍然在下跌趋势中密集触发

**案例：2026-04-24 21:45~22:50 — 4个连续 LONG，全部 SL**

```
真实行情：2315 → 2312（震荡下行）
模型行为：连续做多，逆势被扫
时间间隔：5分钟、60分钟、5分钟（无冷却机制）
```

这与 R1 报告中的案例 B（21:05~22:55 连续9个LONG）完全一致，说明**趋势识别缺失问题未解决**。

### 问题 2：同一时刻 LONG/SHORT 同时触发（方向冲突）

**案例：2026-04-24 01:45**
- LONG prob=0.76 → TP（反弹启动）
- SHORT prob=0.80 → SL（反弹扫损）

两个模型在同一根 K 线上给出相反信号，说明模型缺乏**方向一致性约束**。这在实盘中会导致：
- 如果同时开仓：对冲抵消，白付手续费
- 如果择一开仓：需要额外的方向选择逻辑

### 问题 3：高概率信号不等于高胜率

| 概率区间 | 信号数 | 胜率 |
|---------|-------|------|
| 0.80+ | 3 | 33.3% (1/3) |
| 0.70~0.79 | 4 | 25.0% (1/4) |
| 0.60~0.69 | 4 | 25.0% (1/4) |

**结论**：Platt 校准后的概率与实际胜率不匹配，说明校准器在新数据上失效，或训练数据分布与实盘不一致。

- **R1**: 43 个信号（26小时）→ 平均 1.65 信号/小时

**可能原因**：

- CTI 修复：代码层面已修复，SHORT 模型不再使用错误特征，触发更保守

#### 3. 成功信号模式缺失
- **R1**: 包含 7 种成功模式，分布在 26 小时内
- **R2**: 仅包含 2 种成功模式，集中在 15 分钟内

**关键发现**：R2 缺少 R1 中最稳定的成功模式（趋势启动初期顺势、急涨后反转），说明模型成功依赖于**特定市场状态**，而非稳定预测能力。

### 优先级 1：添加趋势过滤器（R1 已建议，仍未实施）

在 `run_signal.py` 加入 EMA 趋势门控：

```python
ema20 = klines["5m"]["close"].ewm(span=20).mean().iloc[-1]
ema60 = klines["5m"]["close"].ewm(span=60).mean().iloc[-1]

# 只在趋势一致时允许信号
if direction == "LONG" and ema20 <= ema60:
    skip()  # 下降趋势中屏蔽 LONG
if direction == "SHORT" and ema20 >= ema60:
    skip()  # 上升趋势中屏蔽 SHORT
```

**预期效果**：过滤掉 21:45~22:50 的 4 个连续 LONG SL，胜率提升至 40%+

### 优先级 2：信号冷却机制

同方向信号触发后，强制等待 **30 根 K 线（150 分钟）** 才允许再次触发。

### 优先级 3：方向冲突处理

当 LONG/SHORT 同时触发时：
- 方案 A：选择概率更高的方向
- 方案 B：两个都屏蔽（保守策略）
- 方案 C：引入趋势过滤器后，冲突会自然减少

### 优先级 4：提高概率阈值

当前阈值 0.60 → 建议调整为 **0.75**。从数据看，0.60~0.69 区间胜率仅 25%，应该过滤。

### 优先级 5：扩大止损至 0.4%

当前 SL 0.15% 完全在噪音范围内。扩大后需同步降低仓位（margin_pct 从 25% 降至 15%）以控制风险。

## 八、结论

### 重要说明：模型未重新训练

**本次测试使用的是修复前的模型**（训练于 2026-04-22，HORIZON=15，回归头仅正样本训练）。代码层面已应用 CTI 修复，但模型权重仍是旧版本。因此：

- ✅ CTI 修复的效果已体现（SHORT 信号质量提升）
- ❌ HORIZON 对齐、回归头全样本训练的效果**未体现**（需要重新训练模型）
- ❌ 入场价修正的效果**未体现**（回测用，实盘不涉及）

### R1 vs R2 的真实差异

胜率从 22.0% 提升至 27.3%，主要原因是：
1. **CTI 修复**：SHORT 模型不再使用错误特征
2. **市场状态不同**：R2 期间缺少极端行情，信号数量减少 73%
3. **样本量太小**：11 个信号 vs 43 个信号，统计不稳定

### 核心问题依然存在

v1 模型本质上仍是**无趋势感知的均值回归模型**。即使应用了 CTI 修复，策略层面的缺陷未解决：
1. 在单边趋势中连续逆势进场（21:45~22:50 连续 4 个 LONG SL）
2. 缺乏信号冷却机制
3. SL 过窄（0.15% 在噪音范围内）
4. 成功依赖特定市场状态，而非稳定预测能力

### 下一步行动

**优先级 1：添加趋势过滤器**（无需重训，立即见效）
- 在 `run_signal.py` 加入 EMA20/60 趋势门控
- 预期过滤掉 50%+ 的逆势 SL 信号
- 如果有效，再考虑将趋势特征纳入训练集

**优先级 2：重新训练模型**（应用三大 bug 修复）
- HORIZON 15→30：学习更长窗口的价格行为
- 回归头全样本训练：消除分布外预测
- 但即使重训，仍需趋势过滤器

**优先级 3：信号冷却 + SL 扩大**
- 同方向信号间隔 30 根 K 线（150 分钟）
- SL 从 0.15% 扩大至 0.4%，同步降低仓位

**不建议**：在未添加趋势过滤器的情况下直接实盘，即使重新训练模型。
